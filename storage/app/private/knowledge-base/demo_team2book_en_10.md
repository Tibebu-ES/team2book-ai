# Constraints Management\
\
## Overview\
\
Constraints are organizational rules that define the minimum operational coverage required for a schedule to be considered acceptable.\
\
Team2Book continuously evaluates these rules and alerts managers when they are not satisfied.\
\
Constraints help organizations move beyond simple resource assignment and ensure that critical operational requirements are respected.\
\
---\
\
# Why Use Constraints?\
\
## Operational Coverage\
\
Many organizations require a minimum number of professionals to be available during specific periods.\
\
Examples include:\
\
- doctors;\
- nurses;\
- secretaries;\
- clinical assistants;\
- support personnel.\
\
---\
\
## Scheduling Validation\
\
Even when resources are successfully assigned, the resulting schedule may not provide sufficient coverage.\
\
Constraints allow Team2Book to verify that staffing requirements are met.\
\
---\
\
# Purpose of Constraints\
\
Constraints help managers answer questions such as:\
\
- Do we have enough doctors today?\
- Do we have enough coverage this morning?\
- Is minimum staffing available this week?\
- Are support staff levels adequate?\
\
---\
\
# Minimum Staffing Requirements\
\
## Daily Coverage\
\
An organization may require a minimum number of professionals each day.\
\
### Example\
\
At least:\
\
- 4 doctors on duty each day.\
\
If fewer than four doctors are available, Team2Book identifies the issue.\
\
---\
\
# Weekly Coverage Requirements\
\
## Weekly Thresholds\
\
Some organizations evaluate coverage over an entire week rather than a single day.\
\
### Example\
\
At least:\
\
- 6 different doctors available each week.\
\
This helps ensure sufficient physician rotation and service availability.\
\
---\
\
# Morning Coverage Requirements\
\
## Time-Specific Constraints\
\
Organizations may require minimum staffing levels during specific periods of the day.\
\
### Example\
\
At least:\
\
- 3 receptionists every morning.\
\
---\
\
## Benefits\
\
Time-based constraints provide greater operational control than daily requirements alone.\
\
---\
\
# Afternoon Coverage Requirements\
\
## Additional Scheduling Control\
\
Constraints can also be configured for afternoon coverage.\
\
### Example\
\
An organization may require:\
\
- 2 doctors every afternoon;\
- 1 pharmacist every afternoon;\
- minimum administrative support.\
\
---\
\
# Mixed Staffing Constraints\
\
## Multiple Roles\
\
Constraints can combine different types of professionals.\
\
### Example\
\
An organization may require:\
\
- 2 clinical assistants for every 4 doctors performing regular appointments.\
\
---\
\
## Purpose\
\
This helps maintain an appropriate balance between clinical and support resources.\
\
---\
\
# Constraint Evaluation\
\
## Automatic Verification\
\
Team2Book automatically evaluates constraints against the current schedule.\
\
The system compares:\
\
- planned assignments;\
- available professionals;\
- configured staffing requirements.\
\
---\
\
## Continuous Monitoring\
\
As schedules evolve and availability changes, Team2Book continuously re-evaluates constraint compliance.\
\
---\
\
# What Happens When a Constraint Is Not Met?\
\
## Problem Detection\
\
When a constraint is violated, Team2Book identifies the issue automatically.\
\
Examples include:\
\
- insufficient doctors;\
- insufficient nurses;\
- inadequate administrative support;\
- missing role coverage.\
\
---\
\
# Manager Notifications\
\
## Automatic Alerts\
\
When a problem is detected, Team2Book notifies the organization.\
\
Notifications help managers address issues before they create operational problems.\
\
---\
\
## Visibility\
\
Constraint violations can be displayed directly within the scheduling environment.\
\
Managers do not need to manually review every schedule for compliance.\
\
---\
\
# Benefits of Constraint Monitoring\
\
## Reduced Risk\
\
Constraints reduce the chances of:\
\
- understaffing;\
- operational disruptions;\
- scheduling oversights.\
\
---\
\
## Improved Planning\
\
Managers gain confidence that schedules satisfy organizational requirements.\
\
---\
\
## Faster Problem Resolution\
\
Issues are identified automatically rather than discovered after schedules are published.\
\
---\
\
# Practical Examples\
\
## Example 1\
\
Requirement:\
\
- Minimum 4 doctors each day.\
\
Result:\
\
- Team2Book alerts managers when only 3 doctors are available.\
\
---\
\
## Example 2\
\
Requirement:\
\
- Minimum 2 doctors every morning.\
\
Result:\
\
- The system identifies mornings where coverage drops below the threshold.\
\
---\
\
## Example 3\
\
Requirement:\
\
- Minimum 2 secretaries on duty every morning.\
\
Result:\
\
- Managers are notified if the requirement cannot be met.\
\
---\
\
# Constraints and Resource Assignment\
\
## Complementary Functions\
\
Resource assignment and constraints address different objectives.\
\
### Resource Assignment\
\
Answers:\
\
> Where should people work?\
\
---\
\
### Constraints\
\
Answers:\
\
> Do we have enough people working?\
\
---\
\
## Combined Effect\
\
Together, these two mechanisms create more reliable schedules.\
\
---\
\
# Benefits for Managers\
\
Managers benefit from:\
\
- automatic staffing validation;\
- reduced manual reviews;\
- early problem detection;\
- improved operational visibility.\
\
---\
\
# Benefits for Organizations\
\
Organizations gain:\
\
- improved service coverage;\
- more predictable staffing;\
- reduced scheduling risk;\
- improved compliance with staffing policies.\
\
---\
\
# Best Practices\
\
## Start With Critical Constraints\
\
Begin by creating constraints that reflect the most important staffing requirements.\
\
Examples:\
\
- physician coverage;\
- reception coverage;\
- clinical support coverage.\
\
---\
\
## Avoid Excessive Complexity\
\
Too many constraints can make schedule management more difficult.\
\
Focus on requirements that directly impact operational performance.\
\
---\
\
## Review Constraints Regularly\
\
Staffing requirements may change as:\
\
- teams grow;\
- services evolve;\
- organizational priorities shift.\
\
Periodic review keeps constraints relevant.\
\
---\
\
# Relationship With Notifications\
\
Constraint management works closely with Team2Book's notification system.\
\
When a rule is violated:\
\
1. Team2Book detects the issue.\
2. A scheduling problem is created.\
3. Managers are notified.\
4. Corrective action can be taken.\
\
---\
\
# Summary\
\
Constraints allow Team2Book to verify that schedules satisfy minimum operational requirements.\
\
They can be used to enforce:\
\
1. daily staffing requirements;\
2. weekly coverage targets;\
3. morning staffing levels;\
4. afternoon staffing levels;\
5. multi-role staffing ratios.\
\
When a constraint is not satisfied, Team2Book automatically detects the issue and notifies managers, helping organizations maintain adequate staffing levels and deliver reliable operations.\
