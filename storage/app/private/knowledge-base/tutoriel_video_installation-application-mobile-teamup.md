# Installation de l'application mobile Teamup Calendar (Team2Book)

## Présentation

L'application Teamup Calendar est disponible sur les deux principaux systèmes d'exploitation mobiles :
- **iOS** (Apple) — pour les appareils de type iPhone.
- **Android** (Google) — pour les appareils utilisant ce système d'exploitation.

## Installation sur iPhone (iOS)

1. Recherchez et ouvrez l'application **App Store** sur votre iPhone.
2. Dans le menu en bas de l'écran, assurez-vous d'avoir sélectionné **« Rechercher »**.
3. Dans la barre de recherche, entrez **« Teamup Calendar »**.
4. Repérez l'application correspondante (identifiable par son icône).
5. Cliquez sur le bouton **« Obtenir »**.
   > Si l'application a déjà été installée sur un autre de vos appareils, une icône de nuage peut s'afficher à la place.
6. Une fois l'application installée, cliquez sur le bouton **« Ouvrir »**.

## Installation sur Android

Le processus est similaire à celui sur iPhone :

1. Recherchez et ouvrez l'application **Play Store** sur votre appareil.
2. Dans la barre de recherche, entrez **« Teamup Calendar »**.
3. Cliquez sur le bouton **« Installer »**.
4. Une fois l'application installée, cliquez sur le bouton **« Ouvrir »**.

## Connecter l'application à votre calendrier Teamup

Pour fonctionner, l'application mobile Teamup doit être connectée à un calendrier.

1. Recherchez le courriel de bienvenue contenant votre lien d'accès à votre calendrier Teamup.
   > Si vous n'avez pas reçu ce courriel, demandez au gestionnaire de votre équipe de vous transmettre ce lien.
2. À partir de la page d'accueil de l'application Teamup, repérez et cliquez sur le lien **« Continuez sans compte »**.
3. Copiez votre lien d'accès personnalisé et collez-le dans le champ prévu à cet effet (il est aussi possible de le saisir manuellement).
4. Cliquez sur le bouton **« Poursuivre »**.
5. Si le gestionnaire d'équipe a activé la protection par mot de passe, entrez le mot de passe requis.
6. Cliquez sur le bouton **« Poursuivre »**.

Une fois ces étapes complétées, votre calendrier Teamup est installé sur votre application mobile. Vous pouvez dès lors entrer vos disponibilités ou non-disponibilités, et vérifier les ressources qui vous sont attribuées.
