# Tutoriel Team2Book : Consommateurs – Informations supplémentaires

## Introduction

Vous aimeriez caractériser chacun de vos consommateurs? C'est maintenant possible!

Par exemple, une clinique médicale voudra peut-être indiquer le débit de chaque professionnel, c'est-à-dire le nombre de patients par heure rencontré par chaque professionnel en fonction du type d'activité. Cette information peut aider certaines cliniques à attribuer le bon assistant clinique ou infirmière auxiliaire à chaque professionnel.

## Étape préparatoire

Votre gestionnaire d'équipe doit activer la fonction **« Consommateurs : Info supplémentaires »** à partir des paramètres du tableau de bord de Team2Book.

1. Choisissez l'onglet **Consommateurs** de la section **Paramètres** de votre Tableau de bord Team2Book.
2. Repérez le titre **« Consommateurs : Info supplémentaires »**.
3. Activez et sauvegardez.

Vous aurez ensuite l'occasion de nommer le champ **« Info supplémentaire »** selon vos besoins. Dans l'exemple suivant, ce champ a été nommé « débit ».

Finalement, vous pouvez ajouter toutes les options possibles pour ce champ. Par exemple, les professionnels pourront voir :

- de 3 à 6 patients à l'heure pour un suivi de grossesse;
- de 3 à 6 patients à l'heure pour des suivis réguliers.

Les options ajoutées sont donc :

- **Grossesse3, Grossesse4, Grossesse5, Grossesse6**
- **Régulier3, Régulier4, Régulier5, Régulier6**

Vous pouvez également ajouter une couleur pour chaque option. Par exemple :

- options de suivi de grossesse : jaune
- options de suivi régulier : bleu

N'oubliez pas de sauvegarder vos changements.

## Mettre à jour chaque consommateur

Ensuite, mettez à jour chaque consommateur pour indiquer son débit dans le nouveau champ « Info supplémentaires (débit) » :

1. Rendez-vous à la section **Consommateurs** de votre Tableau de bord Team2Book.
2. Cliquez sur l'icône du crayon (mise à jour) à côté de chaque consommateur.
3. Repérez le nouveau champ **« Info supplémentaires (débit) »**.
4. Ajoutez-y une ou plusieurs options (par exemple « Grossesse4 » et « Régulier5 »).
5. Soumettez vos changements.

## Les changements dans Teamup

Lorsqu'un consommateur ajoute une disponibilité, Team2Book tente d'attribuer une ressource à ce consommateur et crée un événement de ressource. La différence est que le champ « Info supplémentaires – Débit » sera automatiquement renseigné avec les débits de ce consommateur.

Par exemple, pour l'événement de ressource créé pour le consommateur B. Thibeault, le champ « Débit » est renseigné automatiquement. Vous pouvez voir la même information dans la vue **Tableau** de Teamup.

Grâce à cette information, la clinique pourra attribuer un assistant clinique au consommateur B. Thibeault en fonction de son débit.
