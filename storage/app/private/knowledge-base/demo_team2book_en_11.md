# Special Events\
\
## Overview\
\
Special Events allow organizations to assign specific team members to specific activities, shifts or resources.\
\
Unlike regular availability-based scheduling, Special Events are used when management needs to explicitly determine:\
\
- who will perform a task;\
- when they will perform it;\
- where they will work.\
\
This functionality extends Team2Book beyond resource allocation and into complete shift management.\
\
---\
\
# What Is a Special Event?\
\
## Definition\
\
A Special Event is a planned assignment where a manager assigns a specific consumer to:\
\
- a specific activity;\
- a specific shift;\
- a specific resource;\
- a specific location.\
\
These assignments are intentional and do not depend exclusively on the normal resource assignment process.\
\
---\
\
# Examples of Special Events\
\
Organizations commonly use Special Events for:\
\
- emergency coverage;\
- night shifts;\
- weekend shifts;\
- surgery assignments;\
- on-call duty;\
- special clinics;\
- reception coverage;\
- operational support activities.\
\
---\
\
# Special Events vs Regular Scheduling\
\
## Regular Scheduling\
\
In a regular scheduling scenario:\
\
1. A professional enters availability.\
2. Team2Book assigns an available resource.\
3. The assignment follows priorities and preferences.\
\
---\
\
## Special Event Scheduling\
\
In a Special Event scenario:\
\
1. Management selects a specific professional.\
2. Management selects a specific activity or shift.\
3. Team2Book records the assignment.\
4. The assignment becomes part of the schedule.\
\
---\
\
# Example: Emergency Room Coverage\
\
## Scenario\
\
A clinic requires a physician to work in the emergency room on a specific morning.\
\
Management decides:\
\
- which physician will work;\
- when the assignment will occur;\
- which resource is involved.\
\
---\
\
## Result\
\
The physician is assigned directly to the emergency room special event.\
\
The assignment becomes visible within Teamup and Team2Book.\
\
---\
\
# Example: Night Shift Assignment\
\
## Scenario\
\
A physician is designated to cover a night shift.\
\
The assignment includes:\
\
- the professional;\
- the date;\
- the night shift event type.\
\
---\
\
## Benefits\
\
This assignment can be tracked and included in workload statistics.\
\
---\
\
# Example: Weekend Coverage\
\
## Scenario\
\
Management schedules weekend coverage for a professional.\
\
The assignment is recorded as a Special Event so that it can be:\
\
- tracked;\
- reported;\
- managed fairly.\
\
---\
\
# Resource-Specific Special Events\
\
## Dedicated Resource Assignments\
\
Some Special Events require a specific resource.\
\
Examples include:\
\
- emergency room;\
- reception desk;\
- surgery room;\
- specialty clinic room.\
\
---\
\
## Purpose\
\
The assigned professional must work in that specific resource for the duration of the event.\
\
---\
\
# Special Events Without Dedicated Resources\
\
## Flexible Assignments\
\
Not all Special Events require a dedicated room.\
\
Some assignments simply indicate that a professional is responsible for a specific activity.\
\
---\
\
## Example\
\
A night shift may not require a separate office assignment.\
\
The professional may continue working from their existing resource while still being assigned to the special event.\
\
---\
\
# Resource Release During Special Events\
\
## Additional Flexibility\
\
When a professional moves to a dedicated special-event resource, their regular office may become available.\
\
---\
\
## Example\
\
If a physician is assigned to the emergency room:\
\
- the emergency room becomes their active assignment;\
- their regular office may be released for use by another professional.\
\
---\
\
## Benefit\
\
This improves overall resource utilization.\
\
---\
\
# Team2Book as a Shift Management System\
\
## Beyond Office Scheduling\
\
Special Events transform Team2Book into a broader workforce scheduling platform.\
\
Organizations can manage:\
\
- work shifts;\
- emergency coverage;\
- evening rotations;\
- weekend assignments;\
- specialty activities.\
\
---\
\

\
## Event Types\
\
Organizations typically create categories representing common types of assignments.\
\
Examples include:\
\
- Emergency\
- Night\
- Surgery\
- Weekend\
- Emergency Front Desk\
- Office Front Desk\
- Scanning Office\
\
---\
\
## Purpose\
\
Categories help standardize assignments and improve reporting.\
\

\
# Fair Distribution of Special Assignments\
\
## Workload Balance\
\
Team2Book can maintain statistics related to Special Events.\
\
This helps organizations distribute assignments more fairly among eligible professionals.\
\
---\
\
## Examples\
\
Managers can monitor:\
\
- emergency shifts completed;\
- night shifts completed;\
- weekend assignments;\
- workload trends.\
\
---\
\
# Statistical Reporting\
\
## Historical Analysis\
\
Special Events generate historical data that can be used for reporting and planning.\
\
Organizations can evaluate:\
\
- assignment frequency;\
- workload distribution;\
- staffing patterns.\
\
---\
\
## Management Benefits\
\
Statistics support fair and transparent scheduling decisions.\
\
---\
\

\
## Dedicated Visibility\
\
Special Events can be displayed within dedicated calendars or sub-calendars.\
\
This allows users to quickly identify:\
\
- emergency assignments;\
- on-call coverage;\
- special schedules.\
\
---\
\
## Organizational Benefits\
\
Separate calendars improve:\
\
- visibility;\
- reporting;\
- operational monitoring.\
\
---\
\
# Why Organizations Use Special Events\
\
## Operational Requirements\
\
Some responsibilities cannot be assigned automatically based solely on office availability.\
\
Examples include:\
\
- emergency coverage;\
- critical roles;\
- legally required staffing assignments;\
- specialized functions.\
\
---\
\
## Controlled Assignment\
\
Special Events provide management with direct control over these important assignments.\
\
---\

Special Events help organizations:\
\
- manage emergency coverage;\
- assign night and weekend shifts;\
- coordinate specialty assignments;\
- track workload distribution;\
- improve reporting;\
- utilize resources more effectively.\
