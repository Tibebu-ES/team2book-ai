# Tutoriel Team2Book : Type d'activité

## Introduction

Est-ce qu'il serait utile pour votre équipe que les consommateurs indiquent non seulement leurs disponibilités, mais indiquent également leur type d'activité?

Supposons par exemple une clinique médicale dont les médecins peuvent voir un certain nombre de patients à l'heure en fonction du type d'activité. Cette clinique pourrait vouloir attribuer des assistants cliniques ou des infirmières auxiliaires pour assister les médecins.

Vous pourriez donc indiquer le débit (c'est-à-dire le nombre de patients à l'heure) pour chacun des médecins en fonction du type d'activité (voyez notre tutoriel vidéo intitulé « Consommateurs - Informations supplémentaires »). Les consommateurs pourraient également indiquer le type d'activité qu'ils comptent effectuer une journée donnée.

Grâce au débit et au type d'activité, vous aurez toute l'information nécessaire pour attribuer vos assistants cliniques à chacun des médecins.

## Étape préparatoire

Votre gestionnaire d'équipe doit activer la fonction **« Type d'activité »** à partir des paramètres de votre tableau de bord Team2Book.

1. Choisissez l'onglet **Champs personnalisés** de la section **Paramètres** de votre Tableau de bord Team2Book.
2. Repérez le titre **« Type d'activité »**.
3. Activez et sauvegardez.

Vous aurez ensuite l'occasion de renommer le champ « Type d'activité » selon vos besoins (dans l'exemple, le nom « Type d'activité » a été conservé).

Finalement, vous pouvez insérer toutes les options possibles pour ce champ et y attribuer une couleur. Par exemple, pour une clinique médicale dont les professionnels effectuent généralement 2 types d'activité (suivis de grossesse et suivis réguliers), on ajoutera les 2 types d'activité suivants :

- **Grossesse**
- **Régulier**

N'oubliez pas de sauvegarder vos changements.

## Les changements dans Teamup

Lorsque les consommateurs entreront leurs disponibilités, ils pourront maintenant renseigner le nouveau champ « Type d'activité ». Lorsque Team2Book créera un événement de ressource, il renseignera automatiquement le champ « Type d'activité » avec l'activité choisie par le consommateur.

Les gestionnaires d'équipe pourront maintenant voir le type d'activité effectué par chacun des consommateurs :

- en pointant leur souris sur un événement de ressource;
- ou à l'aide de la vue **Tableau** de Teamup.

## Exemple combiné : débit + type d'activité

Voyons un exemple où la fonction **« Consommateurs - Informations supplémentaires »** (pour indiquer le débit de chaque consommateur) et la fonction **« Type d'activité »** sont activées en même temps.

- Le 17 février, le consommateur B. Thibeault effectue un suivi de grossesse.
- On peut également voir que le débit de B. Thibeault pour un suivi de grossesse est de 4 patients à l'heure.

La combinaison de ces deux informations permet au gestionnaire d'équipe d'attribuer le bon assistant clinique à B. Thibeault.

> Voyez notre tutoriel vidéo intitulé **« En équipe avec »** pour plus d'informations.

## Point important

Veuillez noter que lorsque le champ « Type d'activité » est renseigné, Team2Book considère l'événement comme un événement de disponibilité, et ce, peu importe le type de sous-calendrier du consommateur.
