# Processus d'intégration Team2Book — Étapes 6 à 9

## Introduction

Après avoir complété la configuration initiale, l'organisation peut commencer la formation des gestionnaires d'équipe et poursuivre la configuration détaillée de Team2Book.

Cette phase permet de bâtir une configuration complète adaptée aux besoins de l'organisation.

Les étapes couvertes :

6. Formation gestionnaire d'équipe #1.
7. Formation gestionnaire d'équipe #2 et configurations de base.
8. Formation gestionnaire d'équipe #3 et fonctions avancées.
9. Formation gestionnaire d'équipe #4 et paramètres avancés.

---

# Étape 6 — Module de formation pour gestionnaire d'équipe #1

## Objectif

Le premier module de formation présente les concepts fondamentaux de Team2Book.

Après ce module, le gestionnaire d'équipe comprend :

- le fonctionnement général de Team2Book;
- la relation entre Team2Book et Teamup Calendar;
- le principe d'attribution automatique des ressources;
- le rôle des disponibilités dans la production des horaires.

---

## Formation recommandée

Complétez le module de formation #1 :

- écoute des tutoriels vidéo;
- lecture de la documentation disponible;
- découverte de l'application.

Document complémentaire :

Consultez le **Guide de formation**.

---

# Étape 6.1 — Bloc d'exercices pour gestionnaires d'équipe #1

## Objectif

Les exercices permettent au gestionnaire d'équipe de pratiquer les fonctions fondamentales.

---

## Exercices réalisés

Le gestionnaire apprend notamment à :

- ajouter une ressource;
- ajouter un consommateur;
- ajouter une disponibilité;
- naviguer dans Team2Book;
- naviguer dans Teamup Calendar.

---

## Résultat attendu

À la fin de cet exercice, le gestionnaire d'équipe doit être capable de comprendre la structure générale de l'environnement Team2Book.

---

# Étape 6.2 — Rencontre de formation #1

## Objectif

Une première rencontre avec un formateur Team2Book permet de valider les apprentissages.

---

## Participants recommandés

La présence du gestionnaire d'équipe est requise.

---

## Objectifs de la rencontre

Durant cette rencontre :

- l'équipe Team2Book fait connaissance avec l'organisation;
- les questions sont répondues;
- les exercices réalisés sont vérifiés;
- les concepts fondamentaux sont validés.

---

# Étape 7 — Module de formation pour gestionnaire d'équipe #2

## Objectif

Ce module présente les éléments nécessaires avant de débuter la configuration complète de l'organisation.

Le gestionnaire d'équipe apprend :

- comment adapter Team2Book aux besoins spécifiques;
- comment structurer les ressources;
- comment configurer les utilisateurs;
- comment préparer la production des horaires.

---

## Document complémentaire

Consultez le **Guide de formation**.

---

# Étape 7.1 — Bloc d'exercices pour gestionnaires d'équipe #2

## Objectif

Approfondir la configuration de base de Team2Book.

Les exercices permettent de pratiquer :

- la modification des paramètres;
- la gestion des ressources;
- la gestion des consommateurs;
- la préparation de l'environnement réel.

---

# Étape 7.2 — Bloc de configurations #2 à #12

## Objectif

Cette étape consiste à configurer les éléments fondamentaux de l'organisation.

Consultez le **Guide de configuration** pour les détails.

---

# Configuration #2 — Détails du client

## Objectif

Définir les informations générales de l'organisation.

Exemples :

- nom de l'organisation;
- langue;
- fuseau horaire;
- heures d'ouverture;
- paramètres généraux.

---

# Configuration #3 — Catégories de ressources

## Objectif

Organiser les ressources en catégories afin de faciliter leur gestion.

Exemples :

- bureaux de médecins;
- bureaux de professionnels;
- postes de travail;
- autres locaux.

---

## Bonne pratique

Créer une structure logique dès le départ facilite :

- l'attribution automatique;
- les statistiques;
- la maintenance future.

---

# Configuration #4 — Rôles des consommateurs

## Objectif

Définir les différents rôles présents dans l'organisation.

Un consommateur représente généralement une personne utilisant les ressources.

Exemples de rôles :

- médecin;
- infirmière;
- pharmacien;
- autre professionnel.

---

## Pourquoi définir les rôles?

Les rôles sont utilisés notamment pour :

- les priorités;
- les contraintes;
- les statistiques;
- les règles d'affectation.

---

# Configuration #5 — Ressources

## Objectif

Ajouter toutes les ressources disponibles.

Une ressource peut représenter :

- un bureau;
- un local;
- un poste de travail;
- un espace partagé.

---

# Configuration #6 — Priorité des consommateurs

## Objectif

Déterminer quels consommateurs doivent être servis en priorité lorsqu'une ressource est limitée.

Exemple :

1. Médecins.
2. Infirmières.
3. Autres professionnels.

---

## Questions à se poser

- Qui doit obtenir une ressource en premier?
- Qui devrait être affecté en dernier lorsqu'il manque de ressources?

---

# Configuration #7 — Préférences de ressources des consommateurs

## Objectif

Définir les préférences individuelles.

Exemples :

- ressource dédiée;
- liste de ressources préférées;
- restrictions particulières.

---

# Configuration #8 — Couleur des sous-calendriers de disponibilités

## Objectif

Définir une stratégie visuelle pour organiser les disponibilités.

Les couleurs peuvent servir à :

- identifier des groupes;
- distinguer des rôles;
- faciliter la lecture du calendrier.

---

# Configuration #9 — Type de sous-calendrier de disponibilités

## Objectif

Déterminer comment les utilisateurs entreront leurs disponibilités.

Options possibles :

- disponibilités;
- non-disponibilités;
- les deux.

---

# Configuration #10 — Heures habituelles de disponibilité

## Objectif

Définir les heures par défaut des consommateurs.

Exemples :

- heure de début habituelle;
- heure de fin habituelle.

---

# Configuration #11 — Préparation des consommateurs

## Objectif

Préparer les informations nécessaires avant l'ajout des utilisateurs.

Il est recommandé de préparer un tableau contenant :

- nom;
- rôle;
- priorités;
- préférences;
- disponibilités habituelles.

---

# Configuration #12 — Consommateurs

## Objectif

Ajouter tous les consommateurs dans Team2Book.

Pour chaque consommateur, définir :

- identité;
- rôle;
- priorités;
- préférences;
- paramètres spécifiques.

---

Exemples :
