# Entering Availability and Non-Availability\
\
## Overview\
\
One of the most important responsibilities for professionals using Team2Book is keeping their availability information up to date.\
\
The scheduling engine depends on accurate availability and non-availability information to:\
\
- assign resources;\
- schedule work periods;\
- allocate offices;\
- support special event assignments.\
\
The process is performed directly inside Teamup Calendar.\
\
---\
\
# Step 1 - Display Your Availability Calendar\
\
## Objective\
\
Before entering availability information, users should simplify the calendar view.\
\
---\
\
## Recommended View\
\
Hide all calendars except:\
\
- your personal availability or non-availability calendar;\
- organization closure calendars when applicable.\
\
---\
\
## Benefits\
\
This approach:\
\
- reduces visual clutter;\
- minimizes mistakes;\
- makes data entry easier.\
\
---\
\
# Showing and Hiding Calendars\
\
## Individual Calendars\
\
Users can display or hide individual calendars as needed.\
\
This allows professionals to focus exclusively on their own schedule information.\
\
---\
\
## Calendar Categories\
\
Calendar categories can also be expanded or collapsed.\
\
This makes it easier to manage large numbers of calendars.\
\
---\
\
## Advantages\
\
Using calendar visibility controls helps users:\
\
- work faster;\
- avoid confusion;\
- reduce data entry errors.\
\
---\
\
# Step 2 - Select the Desired Date\
\
## Objective\
\
Choose the date or period to be scheduled.\
\
---\
\
## Process\
\
Select the desired day directly in the Teamup calendar interface.\
\
This creates a new scheduling event that can be configured as either:\
\
- availability;\
- non-availability.\
\
---\
\
# Step 3 - Configure the Event\
\
## Select the Correct Calendar\
\
Choose the appropriate calendar when creating the event.\
\
Examples include:\
\
- Availability Calendar;\
- Non-Availability Calendar.\
\
---\
\
## Define Working Hours\
\
Specify the time range that applies to the event.\
\
Examples:\
\
- 08:00 to 12:00\
- 08:30 to 17:00\
- 13:00 to 17:00\
\
---\
\
## Save the Event\
\
Once the information has been entered:\
\
1. Review the event details.\
2. Save the event.\
3. Verify that it appears correctly on the calendar.\
\
---\
\
# Why Hours Matter\
\
## Important Scheduling Data\
\
When a user enters start and end times, Team2Book uses those hours during the resource assignment process.\
\
---\
\
## Example\
\
A professional available from:\
\
- 08:00 AM to 12:00 PM\
\
is treated differently than a professional available for the entire day.\
\
---\
\
## Scheduling Impact\
\
Accurate hours improve:\
\
- office assignment quality;\
- resource utilization;\
- scheduling flexibility.\
\
---\
\
# Using the All-Day Option\
\
## Alternative Method\
\
Instead of entering specific hours, users may select:\
\
**All Day**\
\
---\
\
## Benefits\
\
The All-Day option:\
\
- speeds up data entry;\
- reduces administration;\
- simplifies recurring schedules.\
\
---\
\
## Recommended Use Cases\
\
Useful when:\
\
- working a full day;\
- entering vacations;\
- entering full-day absences;\
- entering standard workdays.\
\
---\
\
# Multi-Day Events\
\
## Extended Periods\
\
Availability and non-availability events may span multiple consecutive days.\
\
---\
\
## Example: Vacation\
\
A professional can enter:\
\
- one vacation event covering several days.\
\
instead of creating separate events for each day.\
\
---\
\
## Example: Stable Schedule\
\
A professional with a consistent weekly schedule may create a longer availability period covering multiple days.\
\
---\
\
# Benefits of Multi-Day Events\
\
Advantages include:\
\
- reduced data entry;\
- improved consistency;\
- easier schedule maintenance.\
\
---\
\
# Recurring Events\
\
## Purpose\
\
Recurring events allow users to automate repetitive schedule entries.\
\
---\
\
## Example\
\
A professional who works every Monday can create a recurring availability event rather than entering each Monday individually.\
\
---\
\
## Common Uses\
\
Recurring events are useful for:\
\
- regular clinic schedules;\
- weekly assignments;\
- recurring absences;\
- standard work patterns.\
\
---\
\
# Benefits of Recurring Scheduling\
\
Recurring events help:\
\
- reduce repetitive work;\
- improve schedule consistency;\
- minimize forgotten entries.\
\
---\
\
# Managing Recurring Events\
\
## Modifications\
\
Recurring events can be edited as schedules evolve.\
\
---\
\
## Flexibility\
\
Users can adjust recurring schedules to reflect operational changes or personal availability changes.\
\
---\
\
# Deleting Availability Events\
\
## Removing Events\
\
Availability or non-availability events can be deleted when they are no longer needed.\
\
---\
\
## Single Occurrence vs Entire Series\
\
For recurring events, users may choose:\
\
- a single occurrence;\
- the entire recurring series.\
\
---\
\
## Benefit\
\
This provides flexibility without forcing users to recreate schedules from scratch.\
\
---\
\
# Recommended Availability Timeline\
\
## Enter Information Early\
\
Professionals are encouraged to submit availability information as far in advance as possible.\
\
---\
\
## Benefits\
\
Early schedule entry:\
\
- improves assignment quality;\
- reduces scheduling conflicts;\
- gives managers more planning time.\
\
---\
\
# Monthly Scheduling Cycle\
\
## Suggested Process\
\
A typical planning cycle includes:\
\
1. Availability entry.\
2. Reminder notifications.\
3. Schedule generation.\
4. Resource assignment.\
5. Schedule review.\
\
---\
\
## Goal\
\
Provide Team2Book with the most accurate information possible before scheduling decisions are made.\
\
---\
\
# Impact of Availability Changes\
\
## Schedule Recalculation\
\
Changes to availability may affect:\
\
- office assignments;\
- resource allocations;\
- special event coverage.\
\
---\
\
## Organizational Impact\
\
Late changes can influence the schedules of other professionals, particularly in organizations using shared resources.\
\
---\
\
# Best Practices\
\
## Keep Information Current\
\
Update availability as soon as changes occur.\
\
---\
\
## Use Recurring Events\
\
Automate repetitive schedules whenever possible.\
\
---\
\
## Use Accurate Hours\
\
Specific hours improve scheduling quality.\
\
---\
\
## Review Entries After Saving\
\
Verify that events appear in the correct calendar and on the correct dates.\
\
---\
\
## Enter Information Before Scheduling Deadlines\
\
Earlier availability submission improves planning results.\
\
---\
\
# Summary\
\
Entering availability and non-availability in Teamup is a critical part of the Team2Book scheduling process.\
\
The recommended workflow is:\
\
1. Display only the necessary calendars.\
2. Select the desired date.\
3. Choose the correct calendar.\
4. Enter hours or use the All-Day option.\
5. Save the event.\
6. Use recurring events for repeating schedules.\
7. Keep information up to date.\
\
Accurate availability information allows Team2Book to produce better resource assignments, reduce scheduling conflicts and improve organizational efficiency.\
