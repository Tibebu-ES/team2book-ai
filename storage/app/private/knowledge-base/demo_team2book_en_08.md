# Availability vs Non-Availability\
\
## Overview\
\
One of the foundations of the Team2Book scheduling process is the collection of availability information from team members.\
\
Organizations can choose different approaches depending on how their professionals typically work.\
\
Team2Book supports:\
\
- availability calendars;\
- non-availability calendars;\
- a combination of both approaches.\
\
---\
\
# Why Availability Information Is Important\
\
## Foundation of Scheduling\
\
The quality of the schedules produced by Team2Book depends on the quality of the information entered by team members.\
\
Availability information allows Team2Book to determine:\
\
- who can work;\
- when they can work;\
- which resources can be assigned;\
- which special events can be covered.\
\
---\
\
## Resource Assignment\
\
Availability data is one of the primary inputs used by Team2Book when assigning:\
\
- offices;\
- rooms;\
- workspaces;\
- special assignments.\
\
---\
\
# Availability Calendars\
\
## Definition\
\
An availability calendar is used when a professional enters the periods during which they wish to work.\
\
---\
\
## Typical Use Case\
\
This method is particularly useful for professionals who:\
\
- work irregular schedules;\
- work only a few days per week;\
- have highly variable availability.\
\
---\
\
## Example\
\
A professional who works only:\
\
- Monday;\
- Wednesday;\
- Friday;\
\
would enter those working days as available.\
\
---\
\
## Benefits\
\
- Clear indication of desired work periods.\
- Useful for part-time schedules.\
- Well suited for flexible working arrangements.\
\
---\
\
# Non-Availability Calendars\
\
## Definition\
\
A non-availability calendar is used when a professional enters only the periods when they cannot work.\
\
---\
\
## Typical Use Case\
\
This method is often preferred by professionals who work regularly throughout the week.\
\
---\
\
## Example\
\
A full-time professional may enter only:\
\
- vacations;\
- personal days;\
- conferences;\
- training sessions;\
- absences.\
\
All remaining periods are assumed to be available.\
\
---\
\
## Benefits\
\
- Less data entry.\
- Easier maintenance.\
- Efficient for stable schedules.\
\
---\
\
# Supporting Both Methods\
\
## Flexible Scheduling Model\
\
Within the same organization, different users can use different approaches.\
\
Some professionals may enter:\
\
- availability.\
\
Others may enter:\
\
- non-availability.\
\
Team2Book interprets both methods correctly.\
\
---\
\
## Grouping Calendars\
\
Availability and non-availability calendars are typically grouped accordingly within Teamup.\
\
This organization helps managers quickly understand how information is being entered.\
\
---\
\
# Personal Availability Calendars\
\
## One Calendar Per Team Member\
\
Each team member normally receives a dedicated calendar for entering scheduling information.\
\
This personal calendar is used to manage:\
\
- availability;\
- non-availability;\
- recurring scheduling patterns.\
\
---\
\
## Advantages\
\
- Clear ownership of information.\
- Reduced confusion.\
- Easier maintenance.\
\
---\
\
# Recurring Availability\
\
## Repeating Events\
\
Many professionals have schedules that repeat over time.\
\
Teamup supports recurring events to simplify data entry.\
\
---\
\
## Examples\
\
A professional may work:\
\
- every Monday;\
- every Tuesday morning;\
- every second Friday.\
\
Instead of creating each event individually, a recurring schedule can be configured.\
\
---\
\
## Benefits\
\
- Less manual work.\
- Improved consistency.\
- Easier schedule maintenance.\
\
---\
\
# Multi-Day Availability\
\
## Extended Time Periods\
\
Availability and non-availability periods may span multiple consecutive days.\
\
---\
\
## Examples\
\
### Non-Availability\
\
- Vacation\
- Hospital rotation\
- Conference attendance\
- Leave of absence\
\
---\
\
### Availability\
\
- Stable weekly work schedule\
- Long-term assignment\
- Repeating work cycle\
\
---\
\
## Benefits\
\
This functionality reduces the need to create individual events for every day.\
\
---\
\
# Full-Day Availability\
\
## All-Day Option\
\
Users may indicate that they are available for the entire day rather than entering specific start and end times.\
\
---\
\
## Advantages\
\
- Faster data entry.\
- Simpler schedule creation.\
- Reduced user effort.\
\
---\
\
## Consideration\
\
When not using the all-day option, start and end times become important because Team2Book uses those hours during resource assignment.\
\
---\
\
# Importance of Accurate Time Information\
\
## Why Hours Matter\
\
Specific start and end times help Team2Book:\
\
- allocate resources correctly;\
- avoid conflicts;\
- maximize room utilization.\
\
---\
\
## Example\
\
If a professional is available:\
\
- from 8:00 AM to 12:00 PM;\
\
the system treats that differently than a full-day availability.\
\
---\
\
# Modifying Availability\
\
## Schedule Changes\
\
Availability information can be updated whenever circumstances change.\
\
Examples include:\
\
- schedule adjustments;\
- vacations;\
- unexpected absences;\
- additional workdays.\
\
---\
\
## Dynamic Planning\
\
Because Team2Book continuously evaluates availability information, changes can influence future resource assignments.\
\
---\
\
# Removing Availability Events\
\
## Event Deletion\
\
Availability and non-availability events can be deleted when no longer required.\
\
---\
\
## Recurring Events\
\
When deleting repeating events, users may typically choose between:\
\
- deleting a single occurrence;\
- deleting the entire series.\
\
This provides flexibility when schedules evolve over time.\
\
---\
\
# Recommended Data Entry Timeline\
\
## Enter Information Early\
\
Professionals are encouraged to enter availability information as far in advance as possible.\
\
---\
\
## Benefits\
\
Early availability entry:\
\
- improves scheduling quality;\
- reduces last-minute adjustments;\
- helps managers plan effectively.\
\
---\
\
## Reminder Process\
\
Organizations may use automated notifications and reminders to encourage timely schedule updates.\
\
---\
\
# Impact on Scheduling\
\
Availability information directly affects:\
\
- office assignments;\
- resource allocation;\
- special event coverage;\
- scheduling constraints;\
- operational planning.\
\
Accurate information improves the effectiveness of the entire scheduling process.\
\
---\
\
# Best Practices\
\
## Keep Calendars Updated\
\
Schedules should be updated as soon as changes occur.\
\
---\
\
## Use Recurring Events When Appropriate\
\
Recurring schedules reduce maintenance and improve consistency.\
\
---\
\
## Enter Accurate Hours\
\
Specific times should reflect actual working periods whenever possible.\
\
---\
\
## Choose the Most Appropriate Calendar Type\
\
Professionals should use the availability method that best matches their working patterns.\
\
---\
\
# Summary\
\
Team2Book supports multiple approaches to schedule management:\
\
1. Availability calendars.\
2. Non-availability calendars.\
3. Recurring schedules.\
4. Multi-day events.\
5. Full-day availability entries.\
\
By allowing professionals to enter their schedule information using the method that best fits their work habits, Team2Book can generate more accurate resource assignments and improve overall scheduling efficiency.\
