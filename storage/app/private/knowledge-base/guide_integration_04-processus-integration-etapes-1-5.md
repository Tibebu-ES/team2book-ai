# Processus d'intégration Team2Book — Étapes 1 à 5

## Introduction

L'intégration de Team2Book doit être réalisée progressivement afin d'assurer une adoption réussie par l'organisation.

Cette section présente les premières étapes nécessaires avant de débuter la formation approfondie et la configuration complète de la solution.

Les étapes couvertes :

1. Abonnement Teamup Calendar.
2. Abonnement Team2Book.
3. Identification du coordonnateur des horaires.
4. Création d'une clé d'accès administrateur.
5. Configuration initiale de Team2Book.

---

# Étape 1 — Abonnement Teamup Calendar

## Objectif

Teamup Calendar est le calendrier partagé utilisé par Team2Book.

Un abonnement Teamup Calendar est nécessaire pour utiliser Team2Book.

Teamup permet notamment :

- aux professionnels d'entrer leurs disponibilités;
- aux utilisateurs de consulter les horaires;
- d'afficher les affectations;
- de gérer les permissions d'accès.

---

## Action requise

Si ce n'est pas déjà fait :

1. Créer un compte Teamup Calendar.
2. Choisir un abonnement adapté aux besoins de l'organisation.
3. Préparer le calendrier partagé qui sera utilisé par Team2Book.

Lien utile :

https://www.teamup.com/pricing/

---

# Étape 2 — Abonnement à Team2Book

## Objectif

Team2Book est le moteur d'intelligence qui automatise la gestion des ressources et des horaires.

Team2Book utilise les informations provenant de Teamup Calendar afin de :

- analyser les disponibilités;
- appliquer les règles de priorité;
- respecter les préférences de ressources;
- attribuer automatiquement les locaux;
- détecter les problèmes de planification.

---

## Action requise

Si ce n'est pas déjà fait :

1. Créer un abonnement Team2Book.
2. Sélectionner le forfait approprié.
3. Préparer les informations nécessaires à la configuration.

Lien utile :

https://team2book.com/pricing?lang=fr

---

# Étape 3 — Identifier le coordonnateur des horaires

## Objectif

Chaque organisation doit désigner une personne responsable de l'intégration.

Cette personne est appelée :

**Gestionnaire d'équipe**

Le gestionnaire d'équipe devient la personne-ressource interne pour Team2Book.

---

## Responsabilités du gestionnaire d'équipe

Le gestionnaire d'équipe sera responsable de :

- participer aux formations;
- compléter les exercices;
- configurer Team2Book;
- répondre aux questions des utilisateurs;
- assurer le suivi de l'intégration;
- maintenir la configuration.

---

## Informations à transmettre à Team2Book

Communiquez :

- nom du gestionnaire d'équipe;
- adresse courriel;
- numéro de téléphone;
- poste téléphonique;
- accès direct si disponible.

---

# Étape 4 — Créer une clé d'accès administrateur

## Objectif

Afin que Team2Book puisse communiquer avec le calendrier Teamup Calendar, une clé d'accès administrateur doit être créée.

Cette clé permet à Team2Book d'accéder aux informations nécessaires avec les permissions appropriées.

---

## Action requise

Créer une clé d'accès avec :

- permissions administrateur;
- accès au calendrier utilisé par Team2Book.

---

## Tutoriel

Consultez le tutoriel vidéo :

https://youtu.be/zXnT2Mt6SYc

---

## Important

La clé d'accès administrateur doit être créée avec les permissions nécessaires afin d'éviter des problèmes de synchronisation entre Teamup Calendar et Team2Book.

---

# Étape 5 — Bloc de configuration #1 : Configuration initiale

## Objectif

La configuration initiale permet de créer rapidement un environnement Team2Book fonctionnel.

Cette première configuration sert de fondation pour les étapes suivantes.

---

## Formulaire de configuration initiale

À l'aide du formulaire fourni par Team2Book, l'organisation transmet les informations de base nécessaires.

Il n'est pas nécessaire de connaître immédiatement tous les détails.

Les paramètres pourront être ajustés ultérieurement dans :

**Tableau de bord client → Configuration**

---

## Informations configurées initialement

La configuration initiale peut inclure :

- informations générales de l'organisation;
- paramètres de base;
- premiers utilisateurs;
- structure initiale des ressources;
- paramètres nécessaires au démarrage.

---

## Document complémentaire

Pour plus de détails :

Consultez le **Guide de configuration initiale**.

# Résumé des étapes 1 à 5

Avant de commencer la formation avancée :

| Étape | Action |
|---|---|
| 1 | Obtenir un abonnement Teamup Calendar |
| 2 | Obtenir un abonnement Team2Book |
| 3 | Nommer un gestionnaire d'équipe |
| 4 | Créer une clé d'accès administrateur Teamup |
| 5 | Compléter la configuration initiale |

Une fois ces étapes complétées, l'organisation est prête à débuter la formation des gestionnaires d'équipe.
