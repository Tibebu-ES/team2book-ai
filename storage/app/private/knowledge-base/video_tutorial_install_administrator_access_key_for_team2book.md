\outl0\strokewidth0 \strokec2 # How to Install Your Teamup Administrator Key into Team2Book\
\
## Overview\
\
Before Team2Book can access your Teamup calendars, you must connect your Teamup account by providing your Teamup Administrator Key.\
\
This is a one-time configuration that allows Team2Book to read and update your Teamup calendars.\
\
---\
\
# Step-by-Step Instructions\
\
## Step 1: Log in to Teamup\
\
Log in to your Teamup calendar using your **Administrator** link.\
\
The administrator account is required because Team2Book needs permission to read and write calendar information.\
\
---\
\
## Step 2: Open the Sharing Settings\
\
After logging in:\
\
1. Click the **Settings** button (gear icon) in the upper-right corner.\
2. In the left menu, select **Sharing**.\
\
---\
\
## Step 3: Copy the Administrator Link\
\
In the list of available links:\
\
1. Locate the link named **Administrator**.\
2. Click the **Copy** icon next to the URL.\
\
The administrator key is now copied to your clipboard.\
\
---\
\
## Step 4: Open Team2Book\
\
Return to your Team2Book dashboard.\
\
Navigate to the **Teamup Configuration** section.\
\
---\
\
## Step 5: Paste the Administrator Key\
\
Locate the field named **Teamup Administrator Key**.\
\
Paste the administrator key that you copied from Teamup into this field.\
\
---\
\
## Step 6: Enter the Password (If Applicable)\
\
If your Teamup administrator link is protected by a password, enter that password in the password field located directly below the administrator key field.\
\
---\
\
## Step 7: Save the Configuration\
\
Click **Save** to establish the connection between Teamup and Team2Book.\
\
Once saved, Team2Book will be able to communicate securely with your Teamup calendars.\
\
---\
\
# Summary\
\
Connecting Teamup to Team2Book requires only a few steps:\
\
1. Log in to Teamup using the Administrator link.\
2. Open **Settings \uc0\u8594  Sharing**.\
3. Copy the Administrator link.\
4. Open Team2Book.\
5. Paste the Administrator Key.\
6. Enter the password if your administrator link is password protected.\
7. Click **Save**.\
\
After completing these steps, your Teamup calendar is successfully connected to Team2Book.\
\
---\
\
# Frequently Asked Questions\
\
## Why do I need the Teamup Administrator Key?\
\
The Administrator Key gives Team2Book permission to read and update your Teamup calendars automatically.\
\
## Where can I find the Administrator Key?\
\
In Teamup:\
\
**Settings \uc0\u8594  Sharing**\
\
Look for the link named **Administrator** and copy it.\
\
## Can I use a regular calendar link instead?\
\
No.\
\
Team2Book requires the **Administrator** link because it needs write access to create and update room assignments.\
\
## What if my Administrator link has a password?\
\
Simply enter the password into the password field in the Team2Book configuration page when saving the Administrator Key.\
\
## Do I need to repeat this process?\
\
Normally, no.\
\
The Administrator Key only needs to be configured once unless your Teamup administrator link changes.\
\
## What happens after I save the Administrator Key?\
\
Team2Book establishes a secure connection with your Teamup calendars and can begin reading availability and writing resource assignments.\
\
## Is the Administrator Key stored securely?\
\
Yes.\
\
The Administrator Key is stored in your Team2Book configuration and is used only to communicate with your Teamup calendars.\
