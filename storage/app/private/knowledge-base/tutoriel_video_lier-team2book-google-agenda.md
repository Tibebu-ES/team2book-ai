# Lier Team2Book à Google Agenda (Team2Book)

> Vidéo optionnelle destinée aux utilisateurs avancés qui utilisent déjà Google Calendar.

## Pourquoi établir un lien entre Team2Book et Google Calendar ?

Établir le lien entre votre calendrier Teamup et votre calendrier personnel Google vous permet de consulter vos journées travaillées directement à partir de Google Calendrier, sans devoir ouvrir l'application Teamup. Cela peut être très pratique pour votre organisation personnelle ou familiale — par exemple, pour voir rapidement que vous travaillez de soir à une date donnée.

## Prérequis

1. Votre gestionnaire d'équipe ne doit pas avoir désactivé les flux iCalendar dans les paramètres de Teamup.
2. Votre gestionnaire d'équipe doit avoir autorisé la création d'un sous-calendrier de présence au travail pour vous.

> Puisque le nombre de sous-calendriers influence l'abonnement Teamup nécessaire, les gestionnaires d'équipe voudront généralement activer cette option uniquement pour les utilisateurs souhaitant effectuer le lien.

Le gestionnaire d'équipe peut autoriser cela à partir du tableau de bord de Team2Book, en s'assurant que la case **« Inclure un sous-calendrier de travail »** est réglée à **« Oui »**.

### Vérifier l'autorisation

Sur ordinateur, dans Teamup, regardez dans le menu de gauche : si votre nom apparaît sous la catégorie **« Consommateur Présence »**, cela signifie que l'autorisation a été donnée.

## Qu'est-ce qu'un sous-calendrier de présence au travail ?

Ce sous-calendrier indique tous les quarts de travail pour lesquels une ressource (typiquement un local) vous a été attribuée. Le sous-calendrier de disponibilité seul n'est pas suffisant, car il n'indique pas :
- les événements spéciaux (soir, fin de semaine, sans-rendez-vous),
- les cas où aucune ressource n'était disponible.

## Quels événements sont affichés ?

Par défaut, tous les quarts de travail assignés sont affichés. Si vous avez un horaire régulier et préférez voir uniquement les événements spéciaux (soirs, fins de semaine), vous pouvez demander à votre gestionnaire d'activer l'option **« Inclure uniquement les événements spéciaux »**.

## Comment récupérer le flux iCalendar

1. Connectez-vous à Teamup avec votre lien d'accès personnalisé.
2. Cliquez sur le menu hamburger en haut à droite.
3. Sélectionnez **« Préférences »**, puis **« Flux iCalendar »**.
4. Repérez le calendrier **« Consommateur Présence - [Votre Nom] »**.
5. Cliquez sur le bouton **« Copier »** pour mettre l'URL dans votre presse-papier.

## Insérer le lien dans Google Calendar — à partir de l'ordinateur

1. Allez sur [calendar.google.com](https://calendar.google.com).
2. Dans la barre latérale gauche, cliquez sur le **« + »** à côté de « Autres agendas ».
3. Choisissez l'option **« À partir de l'URL »**.
4. Collez l'URL copiée précédemment et cliquez sur **« Ajouter l'agenda »**.
5. L'agenda apparaît alors dans votre liste à gauche.

## Afficher sur appareil mobile

1. Ouvrez l'application Google Agenda sur votre mobile.
2. Cliquez sur le menu hamburger.
3. Assurez-vous que le nouveau sous-calendrier de présence est bien coché pour qu'il s'affiche.

## Note sur la synchronisation

Une fois le calendrier Teamup lié à Google Calendar, la synchronisation peut prendre de quelques dizaines de minutes à quelques heures, selon le forfait Teamup utilisé.
