# Subscription Plans and Licensing Overview\
\
## Overview\
\
Team2Book is provided as an extension to Teamup Calendar.\
\
As a result, organizations require subscriptions for both:\
\
- Teamup;\
- Team2Book.\
\
The total solution combines the calendar platform provided by Teamup with the scheduling and resource management capabilities provided by Team2Book.\
\
---\
\
# Why Two Subscriptions?\
\
## Teamup Subscription\
\
Teamup provides the core calendar infrastructure used by the organization.\
\
This includes:\
\
- shared calendars;\
- mobile applications;\
- calendar permissions;\
- event management;\
- synchronization features.\
\
---\
\
## Team2Book Subscription\
\
Team2Book provides advanced scheduling functionality including:\
\
- resource assignment;\
- office allocation;\
- availability processing;\
- special event management;\
- constraints;\
- statistics;\
- notifications.\
\
---\
\
# Subscription Sizing\
\
## Capacity Planning\
\
Organizations should select subscription plans based on factors such as:\
\
- number of resources;\
- number of users;\
- organizational complexity;\
- expected growth.\
\
---\
\
## Importance of Proper Sizing\
\
Selecting an appropriate subscription helps ensure that the organization has sufficient capacity for:\
\
- resources;\
- consumers;\
- sub-calendars;\
- scheduling requirements.\
\
---\
\
# Resource Considerations\
\
## Office and Resource Count\
\
The number of resources managed by Team2Book may influence licensing requirements.\
\
Examples include:\
\
- offices;\
- treatment rooms;\
- consultation rooms;\
- shared workspaces;\
- specialized facilities.\
\
---\
\
## Planning for Growth\
\
Organizations should consider future expansion when evaluating subscription requirements.\
\
Examples include:\
\
- new offices;\
- new locations;\
- additional professionals;\
- expanded services.\
\
---\
\
# Teamup Considerations\
\
## Sub-Calendar Usage\
\
Teamup subscriptions are often influenced by the number of sub-calendars required.\
\
Organizations may need sub-calendars for:\
\
- resources;\
- consumers;\
- special events;\
- team schedules;\
- shared calendars.\
\
---\
\
## Monitoring Utilization\
\
Before adding large numbers of calendars, administrators should verify that subscription limits support the intended configuration.\
\
---\
\
# Team2Book Deployment Planning\
\
## Matching Features to Organizational Needs\
\
Organizations should evaluate which Team2Book features will be used during deployment.\
\
Examples include:\
\
- office assignment;\
- special events;\
- calendar synchronization;\
- resource reservations;\
- advanced scheduling features.\
\
---\
\
## Scalable Approach\
\
Many organizations begin with a simpler configuration and expand functionality over time as adoption increases.\
\
---\
\
# Budget Considerations\
\
## Total Platform Investment\
\
When evaluating costs, organizations should consider both components of the solution:\
\
1. Teamup licensing.\
2. Team2Book licensing.\
\
---\
\
## Value Considerations\
\
The combined solution is designed to provide value through:\
\
- reduced scheduling effort;\
- improved resource utilization;\
- automation of repetitive tasks;\
- operational visibility.\
\
---\
\
# Selecting an Appropriate Plan\
\
## Small Organizations\
\
Smaller organizations may require:\
\
- fewer resources;\
- fewer consumers;\
- fewer sub-calendars.\
\
---\
\
## Growing Organizations\
\
Medium-sized organizations often require:\
\
- additional resources;\
- more users;\
- expanded scheduling functionality.\
\
---\
\
## Large Organizations\
\
Complex environments may require:\
\
- larger resource capacity;\
- extensive scheduling management;\
- advanced reporting;\
- broader administrative controls.\
\
---\
\

# Best Practices\
\
## Estimate Future Growth\
\
Avoid sizing only for current requirements.\
\
Consider:\
\
- staffing growth;\
- service expansion;\
- additional locations.\
\
---\
\
## Review Resource Counts\
\
Verify the expected number of:\
\
- resources;\
- consumers;\
- sub-calendars.\
\
before selecting a subscription level.\
\
---\
\
## Evaluate Feature Requirements\
\
Identify which Team2Book capabilities will be used initially and which may be adopted later.\
\
---\
\
## Reassess Periodically\
\
Subscription requirements may evolve as the organization grows and scheduling complexity increases.\
\
---\
\
# Benefits of Proper Licensing Planning\
\
A well-planned subscription strategy helps organizations:\
\
- control costs;\
- avoid capacity limitations;\
- support future growth;\
- maximize platform value.\
\
---\
\
# Relationship to Deployment\
\
Subscription planning should occur early in the implementation process because it influences:\
\
- system configuration;\
- resource creation;\
- user onboarding;\
- organizational scalability.\
\

\
- resources;\
- users;\

- operational complexity;\
- future growth.\
