# Tutoriel — La configuration initiale de Team2Book

## Introduction

La configuration initiale de votre compte Team2Book permet de définir :
- qui sont les membres de votre équipe,
- quelles sont les ressources disponibles à vos bureaux,
- quelles sont les préférences d'attribution des ressources aux membres de l'équipe,
- quelles sont les contraintes à respecter, etc.

Toutes les options définies lors de cette configuration initiale peuvent être modifiées par la suite à partir du tableau de bord.

> Ce tutoriel suppose que vous possédez déjà un compte Team2Book et un compte Teamup.

## Accéder au tableau de bord

Une fois connecté sur le site internet, rendez-vous dans l'espace client et choisissez l'option **« Tableau de bord du client »**.

## Étape 1 — Connexion à votre compte Teamup

- Entrez votre clé d'administrateur du compte Teamup (voir la vidéo dédiée pour savoir comment récupérer cette clé).
- Si votre clé Teamup est protégée par un mot de passe, un champ est prévu pour l'inscrire.

## Étape 2 — Créer une clé d'accès pour le gestionnaire de l'équipe

Normalement, la personne possédant le compte Team2Book est le gestionnaire de l'équipe, mais il est recommandé de vérifier tout de même les informations. Il est possible de :
- recevoir un courriel de bienvenue,
- protéger la clé d'accès par un mot de passe.

## Étape 3 — Détails de l'organisation

Entrez les informations suivantes :
- le nom de l'entreprise,
- le fuseau horaire,
- la langue de configuration.

> Des infobulles sont disponibles pour chaque champ : pointez simplement la souris dessus pour obtenir une explication.

### Nombre de mois planifiés
Indique le nombre de mois pour lesquels des ressources seront attribuées. Par exemple, si l'on est le 1ᵉʳ janvier et que la valeur est « 3 », des ressources seront attribuées pour janvier, février et mars.

### Décalage horaire
Nombre de jours accordés à l'équipe pour entrer leurs disponibilités. Une fois ce délai expiré, Team2Book débute l'attribution des ressources.

### Jour de notification
Journée du mois où un courriel est envoyé aux membres de l'équipe pour leur demander leurs disponibilités.

### Jour de rappel
Journée où un courriel de rappel est envoyé.

### Événements spéciaux
Permet au gestionnaire d'assigner une ressource spécifique à une personne spécifique pour une période donnée (par exemple : déterminer qui travaille à la clinique d'urgence, et à quel moment).

## Étape 4 — Jours de fermeture et horaires

### Jours de fermeture
Indiquez si votre organisation est fermée certains jours (par exemple : samedi, dimanche) afin d'éviter que le système n'y attribue des locaux.

### Horaires d'ouverture et heure de dîner
Team2Book utilise ces informations pour appliquer les contraintes horaires, et pour déterminer s'il est possible de fractionner une période de travail en deux (fractionnement) si les locaux manquent.

## Étape 5 — Catégories de ressources

Les catégories permettent de regrouper vos ressources (par exemple : « Locaux », « Poste réception », « Poste numérisation »). Cela évite, par exemple, qu'un médecin soit assigné par erreur à un poste de réception.

## Étape 6 — Ressources

Ajoutez le nom de chaque ressource spécifique (par exemple : Bureau 1, Bureau 2, Réception urgence) et assignez à chacune :
- une catégorie,
- une couleur de calendrier pour Teamup.

## Étape 7 — Définir les consommateurs

Ajoutez les membres de votre équipe en indiquant :
- le prénom,
- le nom,
- le courriel,
- le rôle.

Le rôle sert à regrouper les membres et à identifier certaines contraintes.

## Étape 8 — Priorités et ressources réservées

Indiquez si un consommateur possède une priorité (1 étant la priorité la plus élevée) sur un bureau spécifique. Lorsqu'un consommateur prioritaire est présent, son bureau lui est réservé ; sinon, ce bureau est partagé avec d'autres.

## Étape 9 — Préférences de ressources

Il est possible d'affiner les préférences de chaque membre de l'équipe, en indiquant quel bureau il préfère en premier choix, en deuxième choix, en troisième choix, etc.

## Étape 10 — Paramètres avancés par consommateur

Pour chaque consommateur, il est possible de configurer :
- le type de saisie : **disponibilité** ou **non-disponibilité**,
- le **fractionnement d'événements** (possibilité de travailler dans deux bureaux différents dans la même journée),
- la **notification par courriel** pour les rappels mensuels,
- le **calendrier de travail**, pour permettre la synchronisation avec Google Calendar ou Outlook,
- un **mot de passe** pour protéger son lien Teamup personnel.

## Fin de la configuration

Une fois la configuration initiale terminée, Team2Book présente le tableau de bord, où il est possible de modifier tous les paramètres en tout temps. Les sous-calendriers Teamup sont créés automatiquement en fonction des données saisies.
