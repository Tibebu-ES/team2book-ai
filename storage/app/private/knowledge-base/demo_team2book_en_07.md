# Filters and Calendar Navigation\
\
## Purpose\
\
Teamup provides several filtering and navigation features that allow users to focus on the information that matters most to them.\
\
These tools help users:\
\
- reduce visual clutter;\
- locate specific schedules;\
- isolate resources;\
- focus on individual professionals;\
- simplify calendar management.\
\
---\
\
# Why Filters Matter\
\
## Large Organizations\
\
As an organization grows, its calendar may contain:\
\
- dozens of professionals;\
- multiple offices;\
- many resources;\
- special events;\
- availability calendars.\
\
Without filtering tools, reading the schedule becomes difficult.\
\
---\
\
## Improved Visibility\
\
Filters allow users to display only the information relevant to a specific task.\
\
This makes schedule interpretation faster and more efficient.\
\
---\
\
# Event Filtering\
\
## Search by Professional\
\
Because Team2Book uses standardized naming conventions, events can be filtered by professional name.\
\
---\
\
## Example\
\
A manager may search for:\
\
```text\
DrAuger\
```\
\
The calendar will display only events related to that professional.\
\
---\
\
## Benefits\
\
This approach makes it easier to:\
\
- review assignments;\
- verify schedules;\
- analyze resource usage.\
\
---\
\
# Focused Calendar Views\
\
## Clean Schedule Review\
\
Filtering allows users to remove unrelated events and focus exclusively on the selected individual or resource.\
\
This creates a simplified and easier-to-read calendar view.\
\
---\
\
# Sub-Calendar Management\
\
## What Are Sub-Calendars?\
\
Teamup organizes information into sub-calendars.\
\
Examples include:\
\
- availability calendars;\
- resource calendars;\
- special event calendars;\
- office calendars.\
\
---\
\
## Why Use Sub-Calendars?\
\
Sub-calendars separate information into logical groups and make navigation much easier.\
\
---\
\
# Displaying a Single Sub-Calendar\
\
## Purpose\
\
Users may choose to view only one sub-calendar at a time.\
\
This is especially useful when entering availability or reviewing assignments.\
\
---\
\
## Example\
\
A professional may choose to display only:\
\
- their personal availability calendar.\
\
All other calendars can be temporarily hidden.\
\
---\
\
## Benefits\
\
- Reduced distractions;\
- easier data entry;\
- cleaner calendar display.\
\
---\
\
# Eye Icon Function\
\
## Purpose\
\
The eye icon provides a quick way to isolate a single sub-calendar.\
\
---\
\
## Behavior\
\
When activated:\
\
- the selected sub-calendar remains visible;\
- other calendars are temporarily hidden.\
\
---\
\
## Usage\
\
This is one of the fastest ways to focus on a specific schedule.\
\
---\
\
# Toggle Individual Calendars\
\
## Individual Control\
\
Each sub-calendar can be shown or hidden independently.\
\
Users can therefore build customized calendar views based on their current needs.\
\
---\
\
## Example\
\
A user may display:\
\
- their availability calendar;\
- one office calendar;\
- one special event calendar.\
\
All other calendars remain hidden.\
\
---\
\
# Category-Based Navigation\
\
## Calendar Categories\
\
Sub-calendars can be organized into categories.\
\
Examples:\
\
- Doctors\
- Nurses\
- Resources\
- Special Events\
- Availability\
\
---\
\
## Category Controls\
\
Users can show or hide all calendars belonging to a category with a single action.\
\
---\
\
## Benefits\
\
This feature is particularly useful in environments containing many calendars.\
\
---\
\
# Toggle Category Display\
\
## Functionality\
\
Selecting a category title can automatically:\
\
- show all calendars within that category;\
- hide all calendars within that category.\
\
---\
\
## Example\
\
A manager may display all:\
\
- doctor calendars;\
\
while hiding:\
\
- nurse calendars;\
- administrative calendars.\
\
---\
\
# Multi-Calendar Views\
\
## Flexible Display\
\
Users are not limited to a single calendar.\
\
Multiple sub-calendars can be displayed simultaneously.\
\
---\
\
## Example\
\
A user may display:\
\
- their availability;\
- assigned offices;\
- emergency schedules.\
\
all within the same calendar view.\
\
---\
\
## Advantages\
\
This supports more advanced scheduling analysis and coordination.\
\
---\
\
# Common Use Cases\
\
## Professional\
\
A professional may choose to view:\
\
- personal availability;\
- assigned office;\
- special duties.\
\
---\
\
## Receptionist\
\
A receptionist may display:\
\
- all professional schedules;\
- office assignments;\
- emergency coverage.\
\
---\
\
## Manager\
\
A manager may review:\
\
- all resources;\
- all professionals;\
- scheduling issues;\
- special events.\
\
---\
\
# Calendar Navigation Best Practices\
\
## Use Categories\
\
Organizing calendars into logical categories simplifies navigation.\
\
---\
\
## Hide Unnecessary Information\
\
Displaying only relevant calendars improves readability.\
\
---\
\
## Use Filters Frequently\
\
Filters provide one of the fastest ways to locate information.\
\
---\
\
## Standardize Naming Conventions\
\
Consistent naming improves search results and makes filtering more effective.\
\
---\
\
# Benefits of Teamup Filtering\
\
Filtering and navigation tools help users:\
\
- find information faster;\
- reduce visual overload;\
- improve calendar understanding;\
- simplify schedule management;\
- work more efficiently.\
\
---\
\
# Practical Example\
\
A physician who wants to enter availability can:\
\
1. Hide all calendars.\
2. Display only their availability calendar.\
3. Enter schedule information.\
4. Re-enable other calendars afterward.\
\
This minimizes mistakes and simplifies the process.\
\
---\
\
# Summary\
\
Teamup provides powerful filtering and navigation tools that improve the scheduling experience.\
\
Key capabilities include:\
\
1. filtering events by professional;\
2. displaying a single sub-calendar;\
3. showing or hiding calendar categories;\
4. displaying multiple calendars simultaneously;\
5. using search and naming conventions to find information quickly.\
\
These features help managers, professionals and administrative staff navigate complex schedules more efficiently while maintaining a clear view of the information most relevant to their work.\
