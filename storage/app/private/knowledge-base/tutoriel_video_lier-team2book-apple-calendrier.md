# Lier Team2Book à Apple Calendrier (Team2Book)

> Vidéo optionnelle destinée aux utilisateurs avancés qui utilisent déjà l'application Apple Calendrier (anciennement iCal).

## Pourquoi établir ce lien ?

Lier votre calendrier de présence Teamup à Apple Calendrier vous permet de consulter vos journées travaillées directement à partir de l'application Apple Calendrier, sans devoir ouvrir Teamup. Cela peut être très pratique pour votre organisation personnelle ou familiale — par exemple, pour voir rapidement que vous travaillez de soir à une date donnée.

## Prérequis

1. Votre gestionnaire d'équipe ne doit pas avoir désactivé les flux iCalendar dans les paramètres de Teamup.
2. Votre gestionnaire d'équipe doit avoir autorisé la création d'un sous-calendrier de présence au travail pour vous.

Le gestionnaire d'équipe peut autoriser cela à partir du tableau de bord de Team2Book, en s'assurant que la case **« Inclure un sous-calendrier de travail »** est réglée à **« Oui »**.

### Vérifier dans Teamup

Dans le menu de gauche sur ordinateur, vous devriez voir votre nom apparaître sous **« Consommateur Présence »**.

Ce calendrier indique tous les quarts de travail pour lesquels une ressource (local) vous a été attribuée. Le calendrier de disponibilité/non-disponibilité seul n'est pas suffisant, car il n'indique pas les assignations manuelles ni les événements spéciaux.

## Récupérer le flux iCalendar

1. Connectez-vous à Teamup avec votre lien d'accès personnalisé.
2. Cliquez sur le menu (icône hamburger) en haut à droite.
3. Sélectionnez **« Préférences »**, puis **« Flux iCalendar »**.
4. Repérez le calendrier **« Consommateur Présence - [Votre Nom] »** et cliquez sur **« Copier »**.

## Lier le calendrier sur mobile (iPhone/iPad)

Il existe quatre façons de procéder :

### 1. Via Apple Mail
1. Ouvrez le courriel contenant le lien que vous vous êtes transmis.
2. Cliquez sur le lien.
3. Appuyez sur **« S'abonner »**, puis sur **« Ajouter »**.

### 2. Si vous n'utilisez pas Apple Mail
1. Appuyez 2-3 secondes sur le lien dans votre application courriel.
2. Choisissez **« Ouvrir ce lien »**.
3. Appuyez sur **« S'abonner »**, puis sur **« Ajouter »**.

### 3. Ajout manuel dans l'application Calendrier
1. Copiez le lien du flux iCalendar.
2. Ouvrez l'application Apple Calendrier.
3. Appuyez sur **« Calendriers »** en bas de l'écran.
4. Sélectionnez **« Nouveau calendrier »** > **« Ajouter un calendrier par abonnement »**.
5. Collez l'URL et cliquez sur **« S'abonner »**.

### 4. Via les Réglages iOS
1. Allez dans **Réglages** de votre mobile > **Calendrier** > **Comptes** > **Ajouter un compte** > **Autre** > **Ajouter un abonnement**.
2. Collez l'URL dans le champ **« Serveur »**.
3. Enregistrez.
