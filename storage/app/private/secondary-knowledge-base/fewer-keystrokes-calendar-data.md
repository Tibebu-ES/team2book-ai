Click and drag
--------------

### All-day and multi-day events

Click on a date or click and drag over multiple days to open the event editor prefilled with the date(s).

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2013/10/250814tu-click-drag-all-multiday-event-1024x576.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2013/10/250814tu-click-drag-all-multiday-event.png)

1. Use the **Month or Multi-week view.**
2. Click and drag over the relevant dates.
3. Release the mouse to open the editor.

When the event editor opens, it will already have the relevant dates for the event.

### Time-specific events

Click and drag over the time grid to pre-fill the event editor with your selected time frame for the event.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2013/10/250814tu-click-drag-time-span-events-1024x576.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2013/10/250814tu-click-drag-time-span-events.png)

1. Use the **Day or Week view**.
2. Click and drag over the relevant times.
3. Release the mouse to open the editor.

The event editor will open with the times already set for the event.

#### Adjust time slots

- To create shorter time slots, click and drag in the calendar just a little, until your desired time slot is highlighted. Change[ the time resolution](http://calendar.teamup.com/kb/change-time-resolution-grid-views/) on your calendar for even finer control.
- Shorten or lengthen event times to the minute in the event editor.  
    [![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2013/10/250814tu-adjust-time-slot-event.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2013/10/250814tu-adjust-time-slot-event.png)

### **Adjust event time**

To easily change the duration of an event, click and drag on its bottom border.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2013/10/250814tu-drag-to-change-event-time.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2013/10/250814tu-drag-to-change-event-time.png)

When changing the start time of an event within the event editor, the end time changes automatically, keeping the duration of the event the same.

To quickly change the event duration:

1. Use a view with a [time grid](https://calendar.teamup.com/kb/change-time-resolution-grid-views/#what-is-the-calendar-resolution).
2. Click and drag the edge of the event to expand or shorten the time.
3. You can also [click and drag](https://calendar.teamup.com/kb/ways-to-quickly-move-events/#option-1-drag-and-drop-in-a-grid-view) the event to move it to a different time.

**Date picker**
---------------

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2013/10/250814tu-date-pickers.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2013/10/250814tu-date-pickers.png)

1. Open one of the date pickers: 
    - Expand the [control panel](https://calendar.teamup.com/kb/hiding-showing-calendars-left-control-panel/) to use the date picker over the Calendars list.
    - Click the arrow next to the date to open the [pop-up date picker](https://calendar.teamup.com/kb/what-is-the-date-picker/#pop-up-date-picker).
2. Click the date you want. Note that you can [scroll](https://calendar.teamup.com/kb/scroll-through-date-picker-with-mouse-or-track-pad/) to move quickly through months.

#### List or Agenda view

Click on the event date in the date picker before clicking the green+ to create an event. The start date will be set accordingly.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2013/10/2508145tu-date-pick-list-event-1024x582.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2013/10/2508145tu-date-pick-list-event.png)

Event editor shortcuts
----------------------

In the event editor, use these shortcuts to save keystrokes:

- Use the tab key to move between event fields.
- Press the Enter/Return key in any of the main fields to save your event and close the window.
- Press the Enter/Return key while in the Description box to create a new line.
- Press escape to exit the event editor.
