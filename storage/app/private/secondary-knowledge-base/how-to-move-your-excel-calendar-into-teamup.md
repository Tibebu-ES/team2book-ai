 </nav> </div><div class="hkb-article__content" itemprop="text">If you’ve been using an Excel-based calendar or gathering events in a spreadsheet, you can import that data directly into a Teamup calendar. You need [administrator access](https://calendar.teamup.com/kb/what-is-an-administrator-link/) to the calendar in order to use the import tool.

### Use supported fields

Teamup’s import tool allows you to import data from a CSV file. The first line of a CSV file is a comma-separated list of field names. So edit your spreadsheet to use the supported field names in the correct format: See all the details [here](https://calendar.teamup.com/kb/import-into-teamup/#supported-fields-in-csv-format). Then save as a CSV file.

### Import the file

Go to **Settings &gt; Import Events.** You can import data to an existing sub-calendar, or create a new one for the import.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2022/03/import-excel-calendar-into-teamup.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2022/03/import-excel-calendar-into-teamup.png)

### Import to multiple sub-calendars

Use the Calendar Name field to specify which sub-calendar the event should be imported to. If an event is to be assigned to multiple sub-calendars, include a list of all calendars separated by the pipe character in the Calendar Name field, like this:

```
Conf. Room Newton|Auditorium
```

See [this article](https://calendar.teamup.com/kb/import-into-teamup/#the-csv-data-format) for detailed instructions.

### Pro Tip
