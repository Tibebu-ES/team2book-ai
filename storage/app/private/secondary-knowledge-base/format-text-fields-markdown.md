Format descriptions with Markdown
---------------------------------

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2020/02/Copy-of-mobile900x900.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2020/02/Copy-of-mobile900x900.png)

[Markdown](https://www.markdownguide.org/getting-started/) is a lightweight markup language with plain-text-formatting syntax. It’s easy to use when you want to format text in event fields with rich formatting capabilities:

- The Description field.
- [Event comments](https://calendar.teamup.com/kb/event-comments/).
- Custom [formatted text fields](https://calendar.teamup.com/kb/custom-formatted-text-fields/).

On a browser, there is also a WYSIWYG editor for rich text formatting in these fields.

### Supported Markdown options

Here are the supported formatting options in Markdown:

Numbered list</td><td>Number + period to create an ordered list</td></tr><tr><td>— Divider</td><td>Three dashes followed by a space to create a horizontal line</td></tr></tbody></table>
