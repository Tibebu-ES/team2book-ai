====================================================

 </nav> </div><div class="hkb-article__content" itemprop="text">When you set up an [iCalendar feed](https://calendar.teamup.com/kb/subscribe-to-teamup-icalendar-feeds/) to share to another calendar program, you have the option to set up an iCal feed for one sub-calendar or all sub-calendars combined.

In some cases, you may want to share multiple sub-calendars from your calendar, but not all of them. You can set up a customized iCalendar feed with selected sub-calendars combined into one feed. Here’s how.

Create a custom iCal feed
-------------------------

To create a custom iCalendar feed with selected sub-calendars, you’ll first create a secure calendar link. Then you’ll open that calendar link to get the iCalendar feed URL.

Only calendar administrators can create the shareable link needed for this process.

1. Open your calendar in a browser.
2. Go to **Settings &gt; Sharing &gt; [Create Link](https://calendar.teamup.com/kb/what-is-a-calendar-link/).**
3. Label the link accordingly (e.g., ‘Selected Sub-calendars for iCalendar Feed’ or whatever is appropriate).
4. Click **Selected Sub-calendars** from the drop-down box.
5. Select the **Read-only** permission for the calendars you want to include in the feed, and leave the other sub-calendars **Not Shared.  
    [![Select the sub-calendars you want to include in your custom iCalendar feed](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![Select the sub-calendars you want to include in your custom iCalendar feed](https://calendar.teamup.com/wp-content/uploads/2021/04/241010tu-select-subcals-for-ical-feed.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2021/04/241010tu-select-subcals-for-ical-feed.png)**
6. Save and copy the link you just made, then open it in a new browser tab.
7. In the link you just opened, go to **Preferences &gt; iCalendar Feeds**:  
    [![Open the new read-only link you created and go to Preferences > iCalendar feeds to get the combined iCalendar feed URL. ](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![Open the new read-only link you created and go to Preferences > iCalendar feeds to get the combined iCalendar feed URL. ](https://calendar.teamup.com/wp-content/uploads/2021/04/241010tu-get-ical-feed.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2021/04/241010tu-get-ical-feed.png)
8. Copy the iCalendar feed URL for **All Calendars.**
9. Use this iCalendar feed URL to sync the selected sub-calendars to Google Calendar, Outlook or another calendar program.
