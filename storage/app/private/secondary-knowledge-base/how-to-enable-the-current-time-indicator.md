 </nav> </div><div class="hkb-article__content" itemprop="text">The current time indicator is a simple red line that runs across the time grid to mark the current time. This makes it easy to see at-a-glance where you are in your day. By default, the current time indicator is off.

Turn on current time indicator
------------------------------

The calendar administrator can enable the current time indicator:

1. Open Teamup in a browser.
2. Go to **[Settings](https://calendar.teamup.com/kb/what-are-the-calendar-settings/) &gt; Date and Time**.
3. Scroll to the **Current Time Indicator** section at the bottom.
