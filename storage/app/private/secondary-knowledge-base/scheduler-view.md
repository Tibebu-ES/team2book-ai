Scheduler view: Side-by-side calendar events
--------------------------------------------

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2015/06/240621tum-scheduler-view-coaches.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2015/06/240621tum-scheduler-view-coaches.png)

Scheduling people, facilities or booking rooms and items are typical tasks when working in a group context.

It is often helpful to view bookings or schedules side by side in these scenarios. For example, you might want to compare bookings for a shared space, employee shifts, or scheduled events and meetings for staff. Take a look at this calendar in different layouts (Month, Multi-week, Week, and Scheduler):

<figure aria-describedby="caption-attachment-9531" class="wp-caption alignright" id="attachment_9531" style="width: 1298px">[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2015/06/240626tu-scheduler-view-compare-layouts.gif)</noscript>](https://calendar.teamup.com/wp-content/uploads/2015/06/240626tu-scheduler-view-compare-layouts.gif)<figcaption class="wp-caption-text" id="caption-attachment-9531">*In Scheduler view, events are organized in columns on an adjustable time grid.*</figcaption></figure>Scheduler view provides a clear visual layout with each calendar shown in its own column.

- See events from multiple calendars next to each other.
- Adjust the date range and resolution as needed.
- [Toggle](https://calendar.teamup.com/kb/hide-calendars/#show-or-hide-sub-calendars-temporarily) calendars on or off from view to view only the relevant events.

How to use Scheduler view
-------------------------

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2015/06/240626tum-scheduler-view-studio-bookings-copy.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2015/06/240626tum-scheduler-view-studio-bookings-copy.png)

1. Choose **Scheduler** from the view selector.
2. Use the arrows or date picker as needed to adjust the visible date(s).
3. Adjust the **Resolution** and **Date range.**

Note: If you don’t see **Scheduler** as an option in the view selector, ask your calendar admin to enable this view in settings (details below).

### **Adjust resolution and date range**

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2015/06/scheduler-view-for-multi-days.gif)</noscript>](https://calendar.teamup.com/wp-content/uploads/2015/06/scheduler-view-for-multi-days.gif)

**Date range:** Choose from Single Day, Multi Day, Weeks, Months, or Years.

**Resolution:** Click the **− or ＋** to adjust the resolution from 5 minutes to 1 year. As you change the resolution, the date range options will adjust.

- If you do not see one of these date range options, adjust the resolution.
- As you adjust the date range, you can set the number of days, weeks, etc.

### Adjust visible columns (sub-calendars)

**[Hide or show selected calendars](https://calendar.teamup.com/kb/hide-calendars/)**: click on the calendar title to show or hide that particular calendar.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2015/06/240626tu-scheduler-view-date-range-resolution.gif)</noscript>](https://calendar.teamup.com/wp-content/uploads/2015/06/240626tu-scheduler-view-date-range-resolution.gif)

**Automatically hide empty columns:** Check the box to automatically hide columns (sub-calendars) which do not have any events displayed in the visible time period.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2015/06/Screen-Shot-2023-11-06-at-11.14.46-AM.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2015/06/Screen-Shot-2023-11-06-at-11.14.46-AM.png)

### Create, move, and copy events

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2015/06/240626tu-scheduler-view-create-move.gif)</noscript>](https://calendar.teamup.com/wp-content/uploads/2015/06/240626tu-scheduler-view-create-move.gif)

- **Create an event:** Click and drag to create an event. The event editor will default to the calendar represented by the column you click in.
- **Move an event:** Drag an event from column A to column B, and the event will be automatically moved to the Column B calendar.
- **Copy an event**: Use **CTRL + drag** to copy an event from column A to column B and the copied version of the event will be automatically assigned to Calendar B.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2015/06/Screenshot-2024-06-26-at-9.54.38%E2%80%AFAM.png)</noscript>](https://teamup.com/examples/ex9)

Enable and configure Scheduler view
-----------------------------------

[Calendar administrators](https://calendar.teamup.com/kb/what-is-the-calendar-administrator/) can enable Scheduler view in **Settings** &gt; **Calendar Views** and adjust the default settings. Once enabled, Scheduler view will be an option in the [view selector](https://calendar.teamup.com/kb/what-are-calendar-views/). These views are available to all current users.

<figure aria-describedby="caption-attachment-8822" class="wp-caption aligncenter" id="attachment_8822" style="width: 501px">[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2015/06/tu-scheduler-configure-defaults.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2015/06/tu-scheduler-configure-defaults.png)<figcaption class="wp-caption-text" id="caption-attachment-8822">*Configure the default resolution and default number of days, weeks, or months shown.*</figcaption></figure>  
Users can adjust the settings while using the calendar in Scheduler view (i.e., change the date range, number of days, and zoom level). The calendar will reset to defaults when a new browser session is started.
