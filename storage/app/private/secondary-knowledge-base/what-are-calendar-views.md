 </nav> </div><div class="hkb-article__content" itemprop="text">A calendar view is the layout for your calendar. Different [calendar views](https://calendar.teamup.com/kb/how-to-use-calendar-views/) enable you to choose how you see calendar data.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2019/11/240619tu-switch-calendar-views.gif)</noscript>](https://calendar.teamup.com/wp-content/uploads/2019/11/240619tu-switch-calendar-views.gif)

Teamup provides several unique calendar views besides the usual day, week, month and agenda/list views:

- [Year](https://blog.teamup.com/wp-content/uploads/2021/04/annualplan-on-teamup.gif) view
- [Scheduler](http://calendar.teamup.com/kb/scheduler-view/) view
- [Timeline](https://calendar.teamup.com/kb/the-timeline-view/) view
- [Table](https://calendar.teamup.com/kb/the-table-view/) view
- [Tiles](https://calendar.teamup.com/kb/the-tiles-view/) view
- [Multi-week](http://calendar.teamup.com/kb/advantages-multi-week/) view
- Multi-day view

Calendar views (browser)
------------------------

Teamup’s web client has 12 different calendar views. Use the view picker (top right) to switch the calendar view:[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2024/06/240619tu-view-picker-all-views-enabled.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2024/06/240619tu-view-picker-all-views-enabled.png)

 **ℹ️ [Learn more](https://calendar.teamup.com/kb/how-to-use-calendar-views/)**

Calendar views (app)
--------------------

In the Teamup app, there are four calendar views available: List, Day, Week, and Month. Open the left sidebar to switch between views. To use other calendar views on a mobile device, open Teamup in a [mobile browser](https://calendar.teamup.com/kb/mobile-browser/).

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2023/03/tu-mobile-calviews1.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2023/03/tu-mobile-calviews1.png)

**ℹ️ [Learn more](https://calendar.teamup.com/kb/how-to-use-calendar-views-on-teamup-mobile-apps/)**

Calendar view settings
----------------------

The calendar administrator can [manage settings](https://calendar.teamup.com/kb/how-to-use-calendar-views/#configure-calendar-views) for calendar views (browser only):

- [Enable or disable](https://calendar.teamup.com/kb/how-to-use-calendar-views/#enable-or-disable-calendar-views) calendar views.
- Set the [default calendar view](https://calendar.teamup.com/kb/how-to-choose-a-default-calendar-view/).
- [Configure](https://calendar.teamup.com/kb/how-to-use-calendar-views/#specific-settings-for-different-calendar-views) calendar views: Some calendar views have default settings which the administrator can manage.

**ℹ️ [Learn more](https://calendar.teamup.com/kb/how-to-use-calendar-views/#configure-calendar-views)**
