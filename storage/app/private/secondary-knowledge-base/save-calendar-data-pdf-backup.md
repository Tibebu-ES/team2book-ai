========================================

 </header></head><body><div class="ht-mobile-toc">**Contents** <nav id="navtoc" role="navigation">1. [Save calendar data to PDF](#save-calendar-data-to-pdf)

 </nav> </div><div class="hkb-article__content" itemprop="text">With Teamup Calendar, you can save your calendar to PDF easily. The calendar data, including all the event details, can be exported to a PDF document for local reference or offline access to calendar data.

Save calendar data to PDF
-------------------------

1. **Display** your calendar in a view which displays the event details: Table view (you can customize which columns are shown to display the details you wish to include in the export) or Agenda or List view and check the box for *Details*.
2. **Select** the date range that you would like to export to PDF .
3. Hold down **Ctrl-P** on PC or **Cmd-P** on Mac to print using the browser’s print function, then print to a PDF file.

You can also use Teamup’s Print &amp; Export PDF option with some additional print settings. To do so, click the **blue menu** icon in the top right of your calendar. Select **Print &amp; Export PDF.**

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2018/08/Print-export-1.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2018/08/Print-export-1.png)

Note that you can **repeat this process periodically** to create and save an updated version of all your calendar data stored locally.
