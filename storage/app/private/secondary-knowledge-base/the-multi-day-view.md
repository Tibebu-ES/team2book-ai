Configure Multi-day view
------------------------

A big advantage of Multi-day view is that it keeps the current day at the forefront of your view. When you open the calendar in Multi-day, the current day will be in the leftmost (first) column. So the events shown will be on current and consecutive days, rather than past events.

In Settings &gt; Calendar views, you can choose how many days are shown in Multi-Day view.

#### Set the number of days

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2024/07/240710tu-multi-day-view-configure.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2024/07/240710tu-multi-day-view-configure.png)

Set the number of days to display in Multi-day view:

- Go to **Settings &gt; Calendar Views.**
- Scroll to **Multi-Day View**.
- Choose from 2 to 6 days.
- You can change the number of days displayed at any time.

Note: if you don’t have access to calendar settings, use a link parameter to adjust the number of days shown. See below for details.

#### Set Multi-day view as the default calendar view

If you are a calendar administrator, you can set Multi-day as the default. If a short-term view of the current day or week is relevant for your users, Multi-day view might be more useful than the more standard Day or Week views.

- With Multi-day, the calendar always opens with the current day in focus.
- To focus on the workweek, set Multi-day to show 5 days.
- If you do granular scheduling and changes to the current day affect the next day’s schedule, using Multi-day view with 2 or 3 days visible works well.

For ongoing use, it’s good to set the calendar’s [start date](https://calendar.teamup.com/kb/change-calendar-start-date/) to the current date. If the calendar is for a specific event like a conference, it’s recommended to set the start date to the beginning of the conference date.

To set the default calendar view:

1. Go to **Settings &gt; Calendar Views**.
2. In the Default View section, select **Multi-Day** from the menu.
3. Scroll down to the Multi-Day View section and choose the number of days to display.
4. Your changes will be saved automatically.

### Use link parameters to adjust the number of days

Calendar link parameters are *key=value* pairs which you can add to the end of a calendar link, for a customized view. You can append *?view=md#* and replace the “#” with the number of days desired in Multi-day view. The calendar will be forced to display in Multi-day view with the number of days chosen.

Read more about [link parameters](http://calendar.teamup.com/kb/calendar-link-parameters/).
