Event filters work on Teamup’s web client (browser) and the Teamup app. [See details](https://calendar.teamup.com/kb/filter-events/).

Three ways to filter events
---------------------------

You can use a combination of different filters to perform an AND logic and narrow down your results. When using multiple filters, the results will display only events matching the criteria for **all** active filters. For example, if you have a keyword filter and a sub-calendar filter, you’ll only see events which belong to that calendar AND contain that keyword.

### By keyword

Use one or more keywords to display only events that contain the keyword(s).

When using multiple keywords, OR logic is used, meaning the results will contain **either one of the keywords or both.**

Use [search operators](https://calendar.teamup.com/kb/filter-events/#search-operators) to apply AND logic or otherwise narrow down your results.

#### By sub-calendar

Select one or more sub-calendar(s) to display only events assigned to the selected sub-calendar(s).

Use in combination with the keyword filter to display only events that match both criteria: Assigned to the selected calendar(s) AND containing the keyword(s).

#### By custom choice field

If you have a [custom choice field](https://calendar.teamup.com/kb/event-fields/), a filter for the choice options will be available below the sub-calendar filter.

To filter by choice field, select the desired option from the filter. Repeat to filter for multiple choices. Select the **Empty** option to filter for events without a selected option in that choice field.

You can also combine the “Empty” option with other choice options to filter for that combination, e.g. See all events without a status (the “Empty” option) **and** with “Hold” status.
