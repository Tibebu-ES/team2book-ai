Here’s how to change the language when using the [Teamup app](https://calendar.teamup.com/kb/teamup-app/) or using Teamup in a [mobile browser.](https://calendar.teamup.com/kb/mobile-browser/)

Scenario 1: Using the Teamup app
--------------------------------

If you are using the Teamup app (iOS, Android), the language is set to default to the language in your device’s settings. For example, on an iPhone:

1. Go to your device Settings
2. Select General, then Language &amp; Region
3. Choose your language.

[![tap iphone settings to change app language](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![tap iphone settings to change app language](https://calendar.teamup.com/wp-content/uploads/2021/03/iphone-settings.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2021/03/iphone-settings.png)

If your device language is not among Teamup’s supported languages, English will be used in the app.

### Scenario 2: Using Teamup in a Mobile Browser

If you are accessing your calendar in a mobile browser, you can use the same method as on [web browsers](https://calendar.teamup.com/kb/change-language-teamup-calendar/):

1. Open your calendar in a [mobile browser](http://blog.teamup.com/2018/07/26/open-calendar-in-browser-from-mobile-app/).
2. Click the blue menu button in the top right and select **Language** from the drop-down box.
3. Choose **More** to see the complete list of languages available.
4. Click on the language you wish to apply to your calendar.
