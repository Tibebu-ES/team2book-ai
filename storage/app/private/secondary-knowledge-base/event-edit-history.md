 </nav> </div><div class="hkb-article__content" itemprop="text">The edit history of any event includes who created an event, when it was created, and when and who last modified the event. This information is available in [the event editor/viewer](https://blog.teamup.com/2018/07/17/what-is-the-event-editor/). It is also visible [on the event page](https://calendar.teamup.com/kb/share-calendar-events-web-pages/).

Edit history in the event editor
--------------------------------

In the event editor/viewer, edit history is shown at the bottom of the event.

You will see **the user (or link) who** created the event, when it was created, and **the user or link to last modify** the event, and **the last time the event was modified**.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2018/08/edit-history-in-event-editor.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2018/08/edit-history-in-event-editor.png)

When accessing the calendar with read-only or add-only access, the event history will show times/dates only and will **not** show the user/link name.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2014/09/tu-event-history-readonly.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2014/09/tu-event-history-readonly.png)

Edit history on an event page
-----------------------------

The edit history of an event can also be seen on the [event page:](https://calendar.teamup.com/kb/share-events-customize-sharing-options/)

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2018/08/edit-history-on-event-page.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2018/08/edit-history-on-event-page.png)

Hover for precise time stamps
-----------------------------

To see the exact date and time the changes were made, hover your mouse over the time displayed in the edit history.

In this example, hover over **2 months** or **10 minutes** as demonstrated:

![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](http://blog.teamup.com/wp-content/uploads/2018/06/edit-history-mouse-hover-to-see-details.gif)</noscript>

To track the full edit history, consider [subscribing to notifications](https://calendar.teamup.com/kb/use-teamup-notifications/).

Edit history in Table view
--------------------------

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2014/09/250417tu-demo-view-recent-event-history-table.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2014/09/250417tu-demo-view-recent-event-history-table.png)

Table view has two columns which can be turned on to [view event edit history.](https://www.teamup.com/learn/interactive-demos/event-history-table-view/) The **Created** column shows the date and time that the event was created. The **Updated** column shows the date and time that the event was last updated.

1. Open Teamup in a browser.
2. Switch to **Table view** in the top right-hand corner.
3. Click **Show/Hide Columns***.*
4. Tick the **Created** and **Updated** columns.

▶️ [See an interactive demo](https://www.teamup.com/learn/interactive-demos/event-history-table-view/)

Note: Calendar administrators can set these columns to be visible as the default configuration for Table view. [More details here](https://calendar.teamup.com/kb/adjust-default-settings-in-table-view/).
