<span>View billing information, change billing details, view invoices, change payment details, change subscription</span>

</div></div><div class="et_pb_module et_pb_accordion et_pb_accordion_0 faq-accordion"><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_0  et_pb_toggle_open">##### <span class="ez-toc-section" id="view-or-change-your-subscription"></span>View or change your subscription<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix"><span>A subscription is always connected to a Teamup master calendar (not a user account). The </span>[calendar administrator](https://calendar.teamup.com/kb/what-is-an-administrator-link/)<span> can view and manage the subscription in the calendar’s </span>[settings](https://calendar.teamup.com/kb/what-are-the-calendar-settings/): Open Teamup in a browser and go to **Settings &gt; Subscription**.

▶️ [View demo](https://app.storylane.io/share/pfzx7wmjmjyl)  
ℹ️ [More information](https://calendar.teamup.com/kb/managing-subscription-plans/)

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_1  et_pb_toggle_close">##### <span class="ez-toc-section" id="download-or-update-invoices"></span>Download or update invoices<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix">Each calendar’s billing history is available in the settings, accessible to the calendar administrator:

1. Open Teamup in a browser.
2. Go to **Settings &gt; Subscription**.
3. Scroll to the **Invoices** section.
4. <span>Click </span>the **blue PDF button** beside an invoice to download it.

To change the information on an invoice, update the [billing contact information](https://calendar.teamup.com/kb/managing-subscription-plans/#update-payment-details): Go to **Settings &gt; Subscription &gt; Billing**, and click **Update Billing Address**.

▶️ [View demo](https://app.storylane.io/share/t53zyv1ksthh)  
ℹ️ [More information](https://calendar.teamup.com/kb/managing-subscription-plans/#access-billing-history)

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_2  et_pb_toggle_close">##### <span class="ez-toc-section" id="change-billing-details-or-payment-method"></span>Change billing details or payment method<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix">The calendar administrator can change the payment method and update billing details in the calendar settings:

1. Open Teamup in a browser.
2. Go to **Settings &gt; Subscription**.
3. Scroll to the **Billing** section.
4. Click **Update Billing Address** and enter the new information, then **Save**.

<span class="s1">▶️</span> [View demo](https://app.storylane.io/share/iickxghrmhwb)  
<span class="s1">ℹ️</span> [More information](https://calendar.teamup.com/kb/managing-subscription-plans/#update-payment-details)

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_3  et_pb_toggle_close">##### <span class="ez-toc-section" id="update-the-billing-contact"></span>Update the billing contact<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix">Communication related to subscriptions are sent via email to the billing contact, so it’s very important to keep this contact information up-to-date. The calendar admin can update the billing contact:

1. Open Teamup in a browser.
2. Go to<span> </span>**Settings &gt; Subscription &gt; Billing.**
3. Click<span> </span>**Update Billing Address.**
4. Update the email address and other details as needed, then<span> </span>**Save**.

<span class="s1">▶️</span> [View demo](https://app.storylane.io/share/iickxghrmhwb)  
<span class="s1">ℹ️</span> [More information](https://calendar.teamup.com/kb/managing-subscription-plans/#update-payment-details)

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_4  et_pb_toggle_close">##### <span class="ez-toc-section" id="cancel-calendar-subscription"></span>Cancel calendar subscription<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix"><span>A [calendar administrator](https://calendar.teamup.com/kb/what-is-an-administrator-link/) can cancel the subscription via the calendar </span>[settings](https://calendar.teamup.com/kb/what-are-the-calendar-settings/):  
<span></span>

1. <span>Open Teamup in a browser</span>
2. <span>Go to **Settings &gt; Subscription**</span>
3. <span>Click **Cancel Subscription** (top right).  
    </span>

<span></span>▶️ [View demo](https://app.storylane.io/share/iickxghrmhwb)  
<span>ℹ️ [More information](https://calendar.teamup.com/kb/how-to-cancel-subscription-plans/) </span>

<span>Historical data, import and export, past events, data storage</span>

</div></div><div class="et_pb_module et_pb_accordion et_pb_accordion_1 faq-accordion"><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_5  et_pb_toggle_open">##### <span class="ez-toc-section" id="import-data"></span>Import data<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix"><span>Teamup supports the import of events from other calendar applications, spreadsheets, databases, and text files. Data can be imported as iCalendar or CSV files.</span>

<span>To use the import feature, open Teamup in a browser and go to **Settings &gt; Import Events**. The import feature is only available to calendar administrators.</span>

ℹ️ [More information](https://calendar.teamup.com/kb/import-into-teamup/)

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_6  et_pb_toggle_close">##### <span class="ez-toc-section" id="export-data"></span>Export data<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix"><span>Teamup provides a</span> bulk export feature to easily export calendar data, including events, event signups, and/or event comments to a file.

To use the bulk export option (available only to<span> </span>[calendar administrators](https://calendar.teamup.com/kb/calendar-administrator-link-explained/)), open Teamup in a browser and go to **Settings &gt; Export Events.**

ℹ️ [More information](https://calendar.teamup.com/kb/bulk-export-calendars-file/)

<div class="et_pb_toggle_content clearfix"><span>Teamup automatically stores events in your calendar that are in the past (</span>**historical data**<span>). Your subscription plan determines how much of your historical data you can access. See [the pricing page](https://www.teamup.com/pricing/) for details. You can [upgrade](https://teamup.com/ksi2xk6ja4d9pr8ewz/events/1688563398) at any time to instantly gain access to more of your historical data. </span>

ℹ️ [More information](https://calendar.teamup.com/kb/access-historical-data/)

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_8  et_pb_toggle_close">##### <span class="ez-toc-section" id="past-events-disappeared"></span>Past events disappeared<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix">Teamup automatically stores past events (historical data). The subscription plan of the calendar determines how much historical data is accessible. For example, o<span>n the free </span>[Basic plan](http://www.teamup.com/pricing.html)<span>, historical data that is more than one year old becomes inaccessible on a rolling basis.</span>

To keep a backup or archive of your calendar’s historical data, you can<span> </span>[export your data](https://calendar.teamup.com/kb/bulk-export-calendars-file/)<span> </span>on a regular basis. You can also [upgrade (temporarily)](https://teamup.com/event/show/id/7TjExRiHrxHuC3fgfNaGKNDV748g6w) to access more historical data for export.

<span> ℹ️ [More information](https://calendar.teamup.com/kb/access-historical-data/)</span>

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_9  et_pb_toggle_close">##### <span class="ez-toc-section" id="back-up-data"></span>Back up data<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix">To keep a backup or archive of your calendar’s historical data, you can<span> </span>[export your data](https://calendar.teamup.com/kb/bulk-export-calendars-file/)<span> </span>on a regular basis. <span>You can also periodically save your calendar to a PDF file via the </span>[Print &amp; Export PDF function.](https://calendar.teamup.com/kb/save-calendar-data-pdf-backup/)<span> </span>

<span>ℹ️ [More information](https://calendar.teamup.com/kb/bulk-export-calendars-file/)</span>

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_10  et_pb_toggle_close">##### <span class="ez-toc-section" id="accidental-deletionrestore-data"></span>Accidental deletion/restore data<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix">If you have accidentally deleted calendar data (events, sub-calendars) or even your entire master calendar, we may be able to help recover the data.

<span>Contact </span>[Teamup Support](mailto:support@teamup.com)<span> right away for help as we only store deleted data in our system for a limited time period. Please be ready to provide the calendar name, link, and a description of the missing data.</span>

<span>ℹ️ [More information](https://calendar.teamup.com/kb/secure-teamup-calendar/#data-backup)</span>

<div class="et_pb_toggle_content clearfix">If you can’t log into your Teamup account (on a browser or on the Teamup app), try these steps:

- Double-check the spelling of your email address and password.
- Be sure you are logging into the email associated with your Teamup account.
- If using the Teamup app, check your mobile browser settings and enable cookies.
- [Reset your user account password](https://teamup.com/ksi2xk6ja4d9pr8ewz/events/1408092664), then login.
- <span>If you go through these checks and still can’t access your account, </span>[contact our support team](mailto:support@teamup.com)<span>.</span>

2. Follow the prompts to log in or register a new account.

5. Choose **Connect an existing calendar.**
6. Type or paste in the calendar link, then tap **Continue**.

To open a [shareable calendar link](https://calendar.teamup.com/kb/how-to-tell-if-your-calendar-access-is-account-based-or-a-link/#link-based-calendar-url) without logging in, [follow these steps](https://calendar.teamup.com/kb/teamup-app/#continue-without-an-account).

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_21  et_pb_toggle_close">##### <span class="ez-toc-section" id="log-in-and-open-calendar-browser"></span>Log in and open calendar (browser)<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix"><span>If you have a Teamup user account:</span>

4. Type or paste the calendar link into the form. [Get more details](https://calendar.teamup.com/kb/add-a-calendar-to-your-dashboard-in-a-browser/).

If you don’t have a Teamup user account, [create one](https://teamup.com/register/). (They’re free.) Then follow the steps above.

If you have a shareable calendar link, you can type or paste it into your browser’s URL bar directly to open the calendar without logging in.

<span class="s1">ℹ️</span> [More information](https://calendar.teamup.com/kb/add-a-calendar-to-your-dashboard-in-a-browser/#access-the-calendar-dashboard)

    </span>

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_71  et_pb_toggle_close">##### <span class="ez-toc-section" id="removing-a-user-does-not-delete-their-calendar-data"></span>Removing a user does not delete their calendar data<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix"><div class="wysiwyg visual-input "><div class="preview readonly">**Calendar data exists independently of calendar users.**

**Sub-calendars and calendar users are<span> </span>[two separate things](https://teamup.com/ksi2xk6ja4d9pr8ewz/events/1682448209).**

- As a calendar admin, you can create a sub-calendar for someone. This creates a *scheduling space* for that individual.
- You also need to add that individual as a calendar user. This is how you *grant access*<span> </span>to the sub-calendar you’ve created as their scheduling space.

So you might have a sub-calendar named Bob Smith, and a calendar user named Bob Smith. While they have the same name, they are two separate things:

- The Bob Smith sub-calendar contains the events (the data) for or related to Bob Smith; these events might be created by the user Bob Smith, or added by someone else (e.g. a supervisor or colleague).
- The Bob Smith calendar user can view and work with the events on that sub-calendar; he might also be able to view events on other sub-calendars, depending on how<span> </span>[his access](https://calendar.teamup.com/kb/share-selected-calendars/)<span> </span>has been customized.

</div></div></div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_72  et_pb_toggle_close">##### <span class="ez-toc-section" id="you-can-access-multiple-calendars-through-your-user-account-dashboard"></span>You can access multiple calendars through your user account dashboard<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix"><div class="wysiwyg visual-input "><div class="preview readonly">**User accounts are always personal**

Teamup user accounts are personal and<span> </span>[always free](https://teamup.com/ksi2xk6ja4d9pr8ewz/events/1287771005). A user account is always tied to an individual.

**Calendars can be organizational**

A calendar, on the other hand, may be managed by an organization. Each calendar may have many independent users and even multiple administrators.

**What this means for you:**

- YOU, an individual person, can access multiple calendars through your personal user account.
- The calendars you access may be your own, or managed by the same or different organizations or groups. You can have different levels of access to these calendars.

**One dashboard for all your calendars**

For example, a user named Mary might have three calendars on her<span> </span>[dashboard](https://calendar.teamup.com/kb/add-calendar-to-dashboard/):

1\. Her personal calendar, which she created. She has full admin access to this calendar.

2\. Her departmental calendar, which her supervisor created. She is an account-based user for this calendar with Modify permission for most of the sub-calendars.

3\. The company calendar, which has company-wide events and holidays. She has read-only access to this calendar through a calendar link.

**Changing calendars does not mean changing accounts**

So, even if you are accessing different calendars than you were previously, there is no need to change or migrate your user account. Your<span> </span>[user account](https://calendar.teamup.com/kb/using-teamup-user-account/)<span> </span>is tied to you, via your email address.

You can<span> </span>[add](https://calendar.teamup.com/kb/add-calendar-to-dashboard/#how-to-add-a-calendar-to-the-dashboard)<span> </span>or<span> </span>[remove](https://calendar.teamup.com/kb/add-calendar-to-dashboard/#remove-a-calendar)<span> </span>calendars from your dashboard as needed. Or, if you are removed from a calendar as an account-based user, that calendar will no longer appear on your dashboard.

</div></div></div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_73  et_pb_toggle_close">##### <span class="ez-toc-section" id="every-teamup-master-calendar-is-managed-separately"></span>Every Teamup master calendar is managed separately<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix">Each Teamup<span> </span>[master calendar](https://calendar.teamup.com/kb/whats-the-difference-between-a-master-calendar-and-sub-calendars/)<span> </span>is managed separately:

- The<span> </span>[subscription](https://teamup.com/ksi2xk6ja4d9pr8ewz/events/1287771005)<span> </span>applies to one master calendar. A calendar subscription for one master calendar will not apply to another, even if both are on your dashboard.
- Calendar access and sharing (via link or account users) must be set up separately for each master calendar.
- Any defaults or changes in the calendar settings apply to that master calendar only.
- You can have access to multiple master calendars through your<span> </span>[Teamup user account](https://teamup.com/ksi2xk6ja4d9pr8ewz/events/1409195101).

You may have<span> </span>[multiple master calendars](https://teamup.com/ksi2xk6ja4d9pr8ewz/events/1293651062)<span> </span>synced on your calendar dashboard. Since each of these is managed separately, you can remove a calendar from your dashboard without changing your access to the other calendars on your dashboard.

You can also have different roles or access levels for different master calendars. For example, you might be a calendar administrator for one calendar and have read-only access to a calendar managed by someone else.

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_74  et_pb_toggle_close">##### <span class="ez-toc-section" id="master-calendar-vs-sub-calendars"></span>Master calendar vs sub-calendars<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix">**Sub-calendars** are individual calendars that are contained within a Teamup **master calendar**.

**Master calendar:** When you [create a calendar](https://teamup.com/calendars) or [launch a live demo](https://www.teamup.com/product/live-demo/)<span> </span>calendar, you are creating a master calendar. A master calendar must contain at least one sub-calendar. The subscription of a master calendar determines how many sub-calendars it can have. The free plan allows up to 8 sub-calendars. ⚠️ If you delete a master calendar, you delete all the sub-calendars it contains and their data.

**Sub-calendars:**<span> </span>You can create and organize multiple sub-calendars in one master calendar. The sub-calendars are listed in the left sidebar of the master calendar. You can delete any one sub-calendar without affecting the other sub-calendars.

ℹ️ [More information](https://calendar.teamup.com/kb/whats-the-difference-between-a-master-calendar-and-sub-calendars/)

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_75  et_pb_toggle_close">##### <span class="ez-toc-section" id="calendar-vs-user-account"></span>Calendar vs user account<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix">A **Teamup calendar** is a calendar which can be used on a web browser, mobile browser, or with Teamup mobile apps. A Teamup calendar can be free or can be upgraded to a paid subscription plan. To create a **new** [**master calendar**](https://calendar.teamup.com/kb/whats-the-difference-between-a-master-calendar-and-sub-calendars/#what-is-a-master-calendar), you’re required to have a user account.

**Teamup [user accounts](https://calendar.teamup.com/kb/using-teamup-user-account/)** are personal and each account is associated with a unique email address. User accounts are free. Your user account gives you a calendar [dashboard](https://calendar.teamup.com/kb/add-calendar-to-dashboard/) where you can access multiple master calendars (both those you have created and those shared with you).

ℹ️ [More information](https://calendar.teamup.com/kb/whats-the-difference-between-a-calendar-and-a-user-account/)

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_76  et_pb_toggle_close">##### <span class="ez-toc-section" id="user-account-vs-shareable-link"></span>User account vs shareable link<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix">With Teamup, the primary way to [share a calendar](https://calendar.teamup.com/kb/how-to-share-your-teamup-calendar-users-groups-links/)<span> </span>is through user accounts. Teamup [**user accounts**](https://calendar.teamup.com/kb/using-teamup-user-account/) provide secure, individualized calendar access through a synced [calendar dashboard](https://calendar.teamup.com/kb/add-calendar-to-dashboard/). You can access multiple Teamup calendars through your dashboard.

- Teamup user accounts are always free for individuals. To create one, [register here](https://teamup.com/register/).
- To [log into](https://teamup.com/login) your Teamup account (on a [browser](https://calendar.teamup.com/kb/using-teamup-user-account/#create-a-user-account) or on the [Teamup app](https://calendar.teamup.com/kb/teamup-app/#log-in-or-sign-up)), you’ll provide your email address and password.
- The calendar administrator can<span> </span>[add and manage users](https://calendar.teamup.com/kb/how-to-manage-account-based-calendar-users/#what-are-account-based-users) and [configure](https://calendar.teamup.com/kb/how-to-manage-account-based-calendar-users/#configure-user-permissions) their access.

A [**shareable calendar link**](https://calendar.teamup.com/kb/share-calendars-access-permissions/) is a way to share a calendar publicly or with a large group. When the calendar does not contain any security-sensitive information, shareable links provide an easy, convenient way to provide access without requiring a login.

- To open a shareable calendar link, type or paste it directly into your browser’s address bar; you can also open a shareable link on the [Teamup app](https://calendar.teamup.com/kb/teamup-app/#continue-without-an-account) without logging in.
- You can [add a shareable calendar link](https://calendar.teamup.com/kb/add-calendar-to-dashboard/#how-to-add-a-calendar-to-the-dashboard)<span> </span>to your<span> </span>[dashboard](https://calendar.teamup.com/kb/add-calendar-to-dashboard/)<span> </span>for easy access.
- The calendar administrator can [create and manage](https://calendar.teamup.com/kb/how-to-share-your-teamup-calendar-users-groups-links/#add-links) shareable calendar links.

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_77  et_pb_toggle_close">##### <span class="ez-toc-section" id="calendar-settings-vs-app-settings-vs-account-settings"></span>Calendar settings vs app settings vs account settings<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix">[**Calendar settings**](https://calendar.teamup.com/kb/what-are-the-calendar-settings/) are the “control center” for the calendar. They are only available on a browser to authorized [calendar administrators](http://blog.teamup.com/2018/12/05/what-is-the-calendar-administrator/).

- On a browser: Select Settings from the blue menu (top right).

[**App settings**](https://calendar.teamup.com/kb/teamup-app/#access-app-settings) are for app-specific configuration, not for the calendar itself. They are available for all users.

- On the Teamup app: Tap the gear icon in the left sidebar.

[**Account settings**](https://calendar.teamup.com/kb/using-teamup-user-account/#manage-your-user-account) are for account user information and preferences. They are only available in a browser to logged-in account users.

- On a browser: Click your user avatar (top right) to open the user menu.

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_78  et_pb_toggle_close">##### <span class="ez-toc-section" id="calendar-menu-vs-user-menu"></span>Calendar menu vs user menu<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix">When using Teamup on a browser, there are two menus available with different options.

The<span> </span>**calendar menu**: Click the blue hamburger menu (top right, next to the view picker).

- If you’re a calendar administrator, you’ll have access to the calendar<span> </span>[settings](https://calendar.teamup.com/kb/what-are-the-calendar-settings/#the-global-calendar-settings)<span> </span>through this menu.
- All calendar users can access the following menu items: 
    - Time zone
    - Print &amp; Export PDF
    - Preferences
    - Calendar Resolution
    - Language
    - Import Invitation…
    - Help

The<span> </span>[**user menu**](https://calendar.teamup.com/kb/using-teamup-user-account/#manage-your-user-account): Click your user avatar (top right, next to the search icon).

- If you’re logged into your Teamup<span> </span>[user account](https://calendar.teamup.com/kb/using-teamup-user-account/), you’ll see these options: 
    - [Dashboard](https://calendar.teamup.com/kb/add-calendar-to-dashboard/)
    - [Profile](https://teamup.com/ksi2xk6ja4d9pr8ewz/events/1378799426)
    - Connected Devices
    - [Notifications](https://teamup.com/ksi2xk6ja4d9pr8ewz/events/1730783339)
    - Logout
- If you are not logged in (or don’t have a user account), the user menu will have options to Login or Register.

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_79  et_pb_toggle_close">##### <span class="ez-toc-section" id="share-calendar-vs-share-event"></span>Share calendar vs share event<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix">With Teamup, you can **[share your calendar](https://calendar.teamup.com/kb/how-to-share-your-teamup-calendar-users-groups-links/#sharing-your-teamup-calendar)** securely by adding users or creating shareable links. You always have centralized control: For each user, group, or link, you choose which sub-calendars to share and assign the level of [access permission](https://blog.teamup.com/2018/07/06/what-are-access-permissions/).

**Sharing an individual event** from Teamup is different than sharing your calendar. Each event on a Teamup calendar can be shared via the [Share menu](https://calendar.teamup.com/kb/share-events-customize-sharing-options/#how-to-share-events). By default, the event sharing options allows you to:

- [share event as a web page](https://calendar.teamup.com/kb/share-calendar-events-web-pages/)with a unique page URL.
- share [add-to-calendar links](https://calendar.teamup.com/kb/add-to-calendar-links/) for the event.
- [post events to social media](https://calendar.teamup.com/kb/share-event-social-media-facebook-twitter/).
- email with pre-populated event details using your installed email client.
- save or[export the event details](https://calendar.teamup.com/kb/export-events-other-calendars/) to another calendar.

The calendar administrator can configure which [sharing options](https://calendar.teamup.com/kb/share-events-customize-sharing-options/)<span> </span>are available.

</div></div><div class="et_pb_toggle et_pb_module et_pb_accordion_item et_pb_accordion_item_80  et_pb_toggle_close">##### <span class="ez-toc-section" id="change-notifications-vs-event-reminders"></span> Change notifications vs event reminders<span class="ez-toc-section-end"></span>

<div class="et_pb_toggle_content clearfix">Teamup<span> </span>[**change notifications**](https://calendar.teamup.com/kb/use-teamup-notifications/#what-are-change-notifications)<span> </span>allow users to be notified when changes are made to events on the calendar. Change notifications can be sent via email or as push notifications. Only Teamup account users can manage change notifications.

[**Event reminders**](https://calendar.teamup.com/kb/can-i-set-event-reminders/)<span> </span>are alerts of upcoming events. They are sent at a specified time before an event starts. Event reminders are only available via<span> </span>**email**<span> </span>for Teamup account users**.**
