The event viewer
----------------

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2019/11/250918tu-event-viewer-read-only-users.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2019/11/250918tu-event-viewer-read-only-users.png)

The event viewer shows a **read-only view** of the event information:

- The event fields that are [visible](https://calendar.teamup.com/kb/how-to-configure-event-fields/#set-visibility-level) to read-only users including inline images, text, links, and attachments. 
    - Note: If a user’s permission is set to [read-only, no details](https://calendar.teamup.com/kb/share-selected-event-information-from-a-teamup-calendar/#no-details-sharing), the event editor will show only the date, time, and calendar name(s); other event details will be hidden.
- A [Print](https://calendar.teamup.com/kb/print-a-calendar/) option and a [Share menu](https://calendar.teamup.com/kb/share-events-customize-sharing-options/).
- [Signups](https://calendar.teamup.com/kb/signup-for-an-event/) and [Comments](https://calendar.teamup.com/kb/event-comments/) if they are enabled for read-only users.

Users with read-only permission can only see events in the viewer (as shown above).

### Event viewer with edit button

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2019/11/250918event-viewer-modify-users-edit-button.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2019/11/250918event-viewer-modify-users-edit-button.png)

When users with [modify permission](https://calendar.teamup.com/kb/what-are-access-permissions/#modify) open an event, they’ll see the event viewer with an edit button.

To open the event editor and make changes to the event, press the **Edit button**.

The calendar administrator can [configure how events open](https://calendar.teamup.com/kb/what-is-the-event-editor/#event-opening-preference) for modify-level users: In the event viewer with an edit button or directly in the event editor. [More details below](https://calendar.teamup.com/kb/what-is-the-event-editor/#event-opening-preference).

The event editor
----------------

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2019/11/250918tu-event-editor-modify-users.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2019/11/250918tu-event-editor-modify-users.png)

Users who have permission to add and/or modify events will use the event editor.

In the event editor, you can add event information, assign sub-calendars, set [recurrence patterns](https://calendar.teamup.com/kb/recurring-events/), adjust the time/date, use custom fields, upload images and files, and more:

1. **Title bar:** Set the title of your event.
2. **Date and [time](https://calendar.teamup.com/kb/time-zone-support/):** Set the start and ending dates and times for the event. If the ‘[All day](https://blog.teamup.com/2018/06/14/quick-tip-create-all-day-or-multi-day-events/)‘ box is checked, the time settings will disappear.
3. **Repeat options:** If the ‘Repeats’ box is checked, the window will expand with options such as Daily, Weekly, and so forth. You can [customize your recurring event](https://blog.teamup.com/2018/06/22/customize-recurring-events/) to repeat for a certain number of times, until a certain date, or ‘forever.’
4. **Calendar selection:** Click in the text box and a drop-down menu of your [sub-calendars](https://blog.teamup.com/2018/06/20/whats-the-difference-between-a-master-calendar-and-sub-calendars/) will appear. You can mouse or arrow down to select a sub-calendar. You can also type in part of a sub-calendars title, then press Enter to select it. An event can be assigned to more than one sub-calendar.
5. **Event fields:** By default, the event editor includes event fields for Who, Where, and a Description. Calendar admins can [configure event fields](https://calendar.teamup.com/kb/how-to-configure-event-fields/) and add [custom event fields](https://calendar.teamup.com/kb/customize-add-new-fields-events/).
6. **Description box:** A full text editor and the ability to [insert images and files](https://calendar.teamup.com/kb/how-to-attach-files-to-events/).
7. **Menu buttons:** **Save**, **Share, Print**. Use **Options** to enable or adjust [Comments](https://calendar.teamup.com/kb/event-comments/) and [Signups](https://calendar.teamup.com/kb/signup-for-an-event/). Once an event is saved the first time, the **Delete** button will also appear.

Teamup [**account users**](http://blog.teamup.com/2018/08/01/what-are-user-accounts/) will also see an option to set[ **event reminders.**](http://blog.teamup.com/2018/08/01/what-are-event-reminders/)

**Event opening preference** 
-----------------------------

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2019/11/250918tu-no-edit-button.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2019/11/250918tu-no-edit-button.png)

The calendar administrator can set the event opening preference for users with modify access.

This setting determines whether events open in the viewer with an edit button, or directly in the event editor.

1. Open Teamup in a browser.
2. Go to **Settings &gt; General Settings**.
3. Scroll to the **Event Opening Preference** section. 
    - **Open in Viewer**: events will open in the non-editable view with the Edit button.
    - **Open in Editor**: events open directly to the event editor, no need to press the button.
