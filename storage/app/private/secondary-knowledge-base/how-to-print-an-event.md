Scale the event for printing
----------------------------

1. In a browser, click on the event to open it.
2. If printing an event page, choose Share &gt; As page to open the event page.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2018/08/print-5.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2018/08/print-5.png)

2. Open your [browser’s print dialog:](https://calendar.teamup.com/kb/how-to-print-calendar-or-event-using-browsers-print-function/)
    - Check the browser’s File menu for a Print option, or
    - Use CTRL + P or CMND + P to open the print dialog.
3. Look for settings. You may need to open an “advanced settings” menu or find an option for “more settings.”
4. Locate the **Scale** field in the print settings.
5. Change the scale to a higher number to increase the font size.
