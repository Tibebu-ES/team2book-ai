 </nav> </div><div class="hkb-article__content" itemprop="text">To get the iCalendar feed URL from a Teamup calendar to set up an [outbound feed](https://calendar.teamup.com/kb/subscribe-to-teamup-icalendar-feeds/):

1. Open the **drop-down menu** in the top right-hand corner, select **Preferences**.
2. Select **iCalendar Feeds**.

[![Find the iCalendar feed URL](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![Find the iCalendar feed URL](https://calendar.teamup.com/wp-content/uploads/2022/12/icalendar-feed-URL.gif)</noscript>](https://calendar.teamup.com/wp-content/uploads/2022/12/icalendar-feed-URL.gif)

A window will open showing the iCalendar feed URLs for the individual sub-calendars. The last one is the feed URL that includes all sub-calendars. **Copy the feed URL you need**.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2022/11/ical-feed-urls-1024x688.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2022/11/ical-feed-urls.png)

### Keep feeds secure

Once an iCalendar feed is set up, it will keep syncing to the destination calendar, unless it is deleted by the subscriber. There may be times when you should re-secure iCalendar feeds; for example, if an employee has left an organization, or a calendar contributor is no longer part of the group. To tighten up security and ensure that no one has unauthorized access to feed data, you can [reset all iCalendar feeds](https://calendar.teamup.com/kb/how-to-reset-all-outbound-icalendar-feeds/). The Reset feature is available only via user account access.
