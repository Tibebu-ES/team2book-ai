 </nav> </div><div class="hkb-article__content" itemprop="text">With Teamup Calendar, you can export **single events** to other calendar services that support the iCalendar file format (.ics). This includes [Google Calendar](http://www.google.com/calendar/about/), [Apple iCal](http://support.apple.com/en-us/HT201747), [MS Outlook](http://www.microsoft.com/en-us/outlook-com/), [Yahoo Calendar](https://login.yahoo.com/?.src=yc&.done=http%3A%2F%2Fcalendar.yahoo.com%2F), and many more. This article discusses how to export a calendar event. You can also [bulk export](https://calendar.teamup.com/kb/bulk-export-calendars-file/) data or [sync Teamup](https://calendar.teamup.com/kb/subscribe-to-teamup-icalendar-feeds/) via iCalendar feeds.

There are 3 ways to export a single event.

Option 1: Context menu
----------------------

1. **Right-click** on the event to open the context menu (shown below). 
    - Events can also be exported from the [event viewer/editor](https://blog.teamup.com/2018/07/17/what-is-the-event-editor/); click an event to open it, then choose Share.
2. Click on **Share** and select the destination calendar application.
3. The event will open in your selected calendar application (see right screenshot below). You can edit the event details or add information as needed, then click Save.

------------------------------

Any event on a Teamup Calendar can be easily shared as a unique, stand-alone webpage.

You may be viewing [an event page](http://calendar.teamup.com/kb/share-calendar-events-web-pages/) because someone shared the link with you. Or perhaps you followed an event link from a notification email.

From an event page, you can easily export the event to various popular calendar services:

<figure class="wp-block-image">[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2018/08/export-event-as-a-page.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2018/08/export-event-as-a-page.png)</figure>Click on the appropriate icon to initiate the export or to share on social media:

<figure class="wp-block-image">[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2018/08/export-to-icons.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2018/08/export-to-icons.png)</figure>Option 3: Export from a mobile device
-------------------------------------

If you are using a mobile device, you can share an event from the Teamup mobile apps or from a mobile browser.

#### Share from the Teamup mobile apps

<div class="wp-block-image"><figure class="alignleft is-resized">[![Event Sharing options via mobile for Teamup Calendar](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![Event Sharing options via mobile for Teamup Calendar](https://calendar.teamup.com/wp-content/uploads/2018/11/Sharingoptions1-1-600x1047.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2018/11/Sharingoptions1-1.png)<figcaption>Tap the Share icon at the top of the event.</figcaption></figure></div><div class="wp-block-image"><figure class="alignright is-resized">[![Event Sharing options via mobile for Teamup Calendar](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![Event Sharing options via mobile for Teamup Calendar](https://calendar.teamup.com/wp-content/uploads/2018/11/sharingoptionsShareMenu1-600x1148.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2018/11/sharingoptionsShareMenu1.png)<figcaption>Choose the sharing option from the menu.</figcaption></figure></div>To share an event from the Teamup mobile app, **tap to open the event**. Then **tap the Sharing icon** in the top right.

A menu of sharing options will open. Select the *Another calendar* option to share the event to another calendar service.

If it is the first time you have shared a Teamup event to your other calendar service, you will need to give permission for Teamup to access your calendar. Then you can adjust the details and description of the event before you save it to your other calendar service.

### Share from a mobile browser

First [**open your calendar in the mobile browser**.](https://calendar.teamup.com/kb/access-calendar-mobile-browser/)

**Tap the 3-bar menu icon**. **Tap Share** to show the drop-down menu of choices.

**Choose your calendar** (iCal for iPhone), then **tap *Add to calendar,*** as shown below:

-------------------------

If you are a calendar administrator, you can export all your Teamup Calendar data to a .csv or .ics file. Then you can import it into another calendar program. See [how to bulk export here](http://calendar.teamup.com/kb/bulk-export-calendars-file/).
