 </nav> </div><div class="hkb-article__content" itemprop="text">The calendar’s start date is the date selected when the calendar is opened. Calendar administrators can set the start date to the current date (most common) or a past or future date.

By default, Teamup calendars are set with the current date as the calendar’s start date. In a scenario like conference planning, it makes sense to select the date of the conference as the default start date.

### Change the default start date

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2015/01/241002tu-change-start-date.gif)</noscript>](https://calendar.teamup.com/wp-content/uploads/2015/01/241002tu-change-start-date.gif)

*Reminder: to access [calendar settings](https://calendar.teamup.com/kb/what-are-the-calendar-settings/), you must have [administrator access](https://calendar.teamup.com/kb/what-is-an-administrator-link/) and use a browser. Calendar settings are [not the same](https://teamup.com/event/show/id/XwuoVn23H2nBQNPLqBxLbuiHH1FbBU) as user account settings.*

1. Go to **Settings &gt; Date &amp; Time.**
2. In the **Start Date** section, use the drop-down menu to select the date you want.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2018/08/default-start-date.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2018/08/default-start-date.png)

#### Start date options

Choose from one of the following options:

- Current Date
- Specific Date
- First day of
- Past Date
- Future Date

For the First day of option, choose the first day of the current quarter, month, or year, or select a specific month.

For Past Date and Future Date, select the number of days in the past or future:

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2015/01/Screen-Shot-2022-11-28-at-9.20.45-AM.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2015/01/Screen-Shot-2022-11-28-at-9.20.45-AM.png)

### Calendar link parameters

Apply configuration options only to selected calendar links with calendar [link parameters](https://calendar.teamup.com/kb/calendar-link-parameters/).

Supported start date configurations include:

- **date=yyyy-mm-dd** Sets start date to a specific date, e.g. date=2013-09-09.  
    This is useful for calendars that are used to plan for a specific event, like a conference.
- **date=y1** Sets start date to January 1 of the current year.
- **date=q1** Sets start date to the first day of the current quarter.
- **date=m1** Sets start date to the first day of the current month.
- **date=today** Sets start date to the current calendar day.

Example: below is a calendar link with the initial calendar date, view, and side panel setting configured through link parameters. Click to view the calendar as set by the link parameters:  
[http://teamup.com/ks48cf2135e7e080bc?date=2013-09-09&amp;view=w&amp;sidepanel=c](http://teamup.com/ks48cf2135e7e080bc?date=2013-09-09&view=w&sidepanel=c)
