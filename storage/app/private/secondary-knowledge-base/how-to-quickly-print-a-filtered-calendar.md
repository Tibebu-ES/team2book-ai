 </nav> </div><div class="hkb-article__content" itemprop="text">If you already have a Teamup calendar, you can create custom printouts that include only certain events.

For example, you could print a list of tasks with “Open” status from your own sub-calendar. Or print all jobs assigned to a certain team member that are “On Hold.” To do this, toggle the sub-calendars to show only the relevant one(s), then use filters to display only the relevant events for your printout.

Print a calendar with filtered events
-------------------------------------

1. Open Teamup in a browser.
2. Toggle sub-calendars and use filters to display only the events you want to print.
3. Adjust the date range and choose the [calendar view](https://www.teamup.com/learn/product-tips/choose-the-best-calendar-view/) you want.
4. Click the blue hamburger menu (top right).
5. Click **PDF** **Print &amp; Export**.
6. A dialog with printing options will open: 
    - Color: Full Color or Eco.
    - Sidebar: Visible or hidden.
    - Orientation: Portrait or Landscape.
7. Select the options you want, then click the green Continue button.
8. Adjust other settings in your browser’s print dialog, if needed, then print or download the PDF.

### <span style="font-size: 20px;">Alternate: Use a designated sub-calendar</span>

If you want to include only some events from your calendar, put they don’t all belong to a certain sub-calendar or have the same status, you can put them all on one sub-calendar and hide other sub-calendars.

1. In a browser, open Teamup and go to **Settings &gt; Calendars**.
2. [Create](https://www.teamup.com/learn/interactive-demos/create-and-organize-sub-calendars/) a new “Printable Events” sub-calendar.
3. Go back to the calendar. [Duplicate](https://www.teamup.com/learn/interactive-demos/copy-or-duplicate-an-event/) all the events you want to include on the printable to the new sub-calendar.
4. Once you’ve duplicated all the events you want to include on the printable, [toggle](https://www.teamup.com/learn/interactive-demos/toggle-sub-calendars-on-and-off-from-view/) all sub-calendars off except for the Printable Events sub-calendar.
5. Adjust the date range and choose the [calendar view](https://www.teamup.com/learn/product-tips/choose-the-best-calendar-view/) you want.
6. Click the blue hamburger menu (top right).
7. Click **PDF** **Print &amp; Export**.
8. A dialog with printing options will open: 
    - Color: Full Color or Eco.
    - Sidebar: Visible or hidden.
    - Orientation: Portrait or Landscape.
9. Select the options you want, then click the green Continue button.
10. Adjust other settings in your browser’s print dialog, if needed, then print or download the PDF.
11. When you’re done making printouts, go to Settings &gt; Calendars and [deactivate](https://www.teamup.com/learn/interactive-demos/deactivate-or-delete-a-sub-calendar/) the Printable Events sub-calendar. It will still be there if you need it (just activate it) but it won’t clutter up your calendar view in the meantime.

### Pro Tips

- You can print a schedule or calendar with a [custom title](https://calendar.teamup.com/kb/print-schedule-calendar-with-custom-title/).
- [Use these templates to](https://www.teamup.com/printable-calendars/) print a blank calendar at any time in the style you want.
- If event titles are not displaying fully, [adjust](https://calendar.teamup.com/kb/change-time-resolution-grid-views/) the calendar resolution to create more space for each event so the title can be seen in full, then print.
