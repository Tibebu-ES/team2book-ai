 </nav> </div><div class="hkb-article__content" itemprop="text">Copying an event allows you to move it to a different date/time (or creates a copy at the same date/time). Duplicating an event allows you to copy it to a different sub-calendar(s).

You can copy or duplicate an event using the context menu or drag-and-drop.

Use the context menu
--------------------

The **Copy to** option replicates the event exactly as is to a different time/date. The **Duplicate** option opens a new copy of the event so you can change the sub-calendar or other details.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2014/10/240801tu-copy-duplicate-context-menu.gif)</noscript>](https://calendar.teamup.com/wp-content/uploads/2014/10/240801tu-copy-duplicate-context-menu.gif)

### Copy to a different time/date

1. Right-click an event and **select Copy to.**
2. On the pop-up date picker, click the date you want the new event to be on.

### Duplicate to a different sub-calendar

1. Right-click an event and select **Duplicate**. The event editor will open with the original event info pre-populated, but without a sub-calendar selected.
2. Select one or more sub-calendars and edit any details as needed.
3. **Save** the new event.

It’s possible to duplicate a read-only event to a different sub-calendar, as long as you have add or modify permission to that sub-calendar.

Drag and drop events
--------------------

Use **CTRL + drag (PC)** or **OPTION (Alt) + drag (Mac)** to quickly copy or duplicate events in certain calendar views.

### Grid views: Copy to different date/time

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2014/10/240801tu-drag-drop-grid-views-copy.gif)</noscript>](https://calendar.teamup.com/wp-content/uploads/2014/10/240801tu-drag-drop-grid-views-copy.gif)

On any of the calendars with [a grid view](https://calendar.teamup.com/kb/change-time-resolution-grid-views/), use **CTRL + drag (PC) or OPTION (Alt) + drag (Mac)** to copy an event to a different time/date.

### Scheduler view: Copy, duplicate, or both

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2014/10/240801tu-drag-drop-copy-scheduler.gif)</noscript>](https://calendar.teamup.com/wp-content/uploads/2014/10/240801tu-drag-drop-copy-scheduler.gif)In [Scheduler](https://calendar.teamup.com/kb/scheduler-view/) view, use **CTRL + drag (PC)** or **OPTION (Alt) + drag (Mac):**

- Drag across the time grid to copy to a different date/time.
- Drag across columns to duplicate to a different sub-calendar.
- Drag across both to duplicate to a different sub-calendar and different date/time.
- On any event, click and drag to adjust the duration.

### Timeline view: Copy, duplicate, or both

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2014/10/240801tu-drag-drop-copy-timeline.gif)</noscript>](https://calendar.teamup.com/wp-content/uploads/2014/10/240801tu-drag-drop-copy-timeline.gif)

In [Timeline](https://calendar.teamup.com/kb/the-timeline-view/) view, use **CTRL + drag (PC)** or **OPTION (Alt) + drag (Mac):**

- Drag across the time grid to copy to a different date/time.
- Drag across rows to duplicate to a different sub-calendar.
- Drag across both to duplicate to a different sub-calendar and different date/time.
- On any event, click and drag to adjust the duration.
