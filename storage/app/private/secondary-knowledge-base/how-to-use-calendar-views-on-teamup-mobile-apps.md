Switch calendar views
---------------------

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2023/03/260105tu-app-switch-calendar-views.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2023/03/260105tu-app-switch-calendar-views.png)

To use a different calendar view:

1. Swipe or tap to open the left sidebar.
2. The available calendar views are listed under the title of the calendar. Tap the one you want to use.

How to use calendar views
-------------------------

For all calendar views on mobile:

- **Swipe down or tap ▾ to open the date picker.** Swipe to move between months. Tap any date to scroll there immediately.
- **Tap an event** to open the event viewer/editor and see all event details.
- To create an event, **tap in the time grid (Day, Week, Month)** or **tap the green ✚** in the bottom right.
- If the view is busy**, hide sub-calendars**: swipe to open the left sidebar, then **tap to toggle calendars** on or off from view.

### List view

List view is an excellent choice for the smaller screen space of a mobile device. List view displays a “stack” of events. There is more room to show the event title, and list view displays the event time and calendar name(s) as well.

[![A mobile screen shows the Teamup app in list view](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![A mobile screen shows the Teamup app in list view](https://calendar.teamup.com/wp-content/uploads/2023/03/tu-mobile-calviews2.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2023/03/tu-mobile-calviews2.png)

- **Scroll up or down to see future or past events.** If the current date moves out of view, a blue arrow will appear in the bottom left. Tap the arrow to scroll all the way back to the current date. The current date will show in blue.
- **Display or hide empty days**. Swipe or tap to open the left sidebar, then tap the gear icon. Use the toggle to Display empty days or not.

### Day view[![A mobile screen shows the Teamup app in Day view](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![A mobile screen shows the Teamup app in Day view](https://calendar.teamup.com/wp-content/uploads/2023/03/smartmockups_lfle03lf.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2023/03/smartmockups_lfle03lf.png)

- **Swipe left or right to move between days**. If you swipe off the current day, a blue arrow will appear in the bottom left. Tap that arrow to move back to the current day immediately.

### Configuring calendar views

Calendar views on mobile do **not** have the same configuration options as [calendar views](https://calendar.teamup.com/kb/how-to-use-calendar-views/) on a browser. Many of the browser settings for shared calendar views will **not** take effect in the mobile app. For example, setting a visible time range or hiding weekends on calendar settings in a browser will **not** carry through to the mobile apps.
