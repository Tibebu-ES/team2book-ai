 </nav> </div><div class="hkb-article__content" itemprop="text">You can search the events on your Teamup calendar when using the [Teamup app](https://www.teamup.com/apps/) (iOS, Android). Note that the search function will filter events within the displayed date range. Swipe up and down or left and right to see results in the past or future.

Choose the best view for searching
----------------------------------

The List view may be the easiest to see all search results, as you can see more event details and scroll easily to see search results in any time period. On the other hand, search results displayed in the Month view may provide you with insights on how the events are spread across the calendar grid. You can switch among any of the four views in the left sidebar.

Search by keyword, custom field, or sub-calendar
------------------------------------------------

[See this video](https://calendar.teamup.com/wp-content/uploads/2022/06/tu-filter-mobile-video.mp4) for more details.*</figcaption></figure>1. **Tap the magnifying glass icon** (top right) to open the filter dialog.
2. **Enter a keyword,** **select an option from a [custom field](https://calendar.teamup.com/kb/create-custom-field-multiple-choices/), and/or select sub-calendar(s)**. You can also use a combination of filters.
3. **Tap the check mark** in the top right of the filter dialog to see the results. The search box above the calendar will show currently enabled filters.
4. Swipe to different dates to see search results over other time ranges.
5. To clear the filter parameters, **click the x icon in the search box** and you will return to an unfiltered calendar view.

Note: If you close the app while the search results are displayed, when you re-open the app, you will return to the previous search results.

#### Sub-calendar visibility

On the left sidebar, you can select which sub-calendars to view. It’s important to know that **currently hidden sub-calendars will not be included in the search**. If you are not seeing the filtered results you expect, check the sidebar to ensure that all relevant sub-calendars are visible.
