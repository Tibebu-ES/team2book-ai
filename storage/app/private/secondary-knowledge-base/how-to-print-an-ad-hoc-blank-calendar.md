Create a custom printable blank calendar
----------------------------------------

There are three easy ways to create customized calendars with Teamup: Use the printable calendar widget, a live demo calendar, or your own Teamup calendar.

**🔗 For premade blank printable calendars, check out [Teamup’s printable calendar collection](https://www.teamup.com/printable-calendars/).**<span class="ez-toc-section" id="make-a-custom-blank-calendar"></span>

### <span class="ez-toc-section" id="teamup-printable-calendar-widget"></span>Teamup printable calendar widget

Use our handy [printable calendar widget](https://www.teamup.com/printable-calendars/#create-a-customized-blank-calendar) to quickly create a custom blank calendar to download and print. Enter the title and starting date, the set the other options. Click the button to generate your custom blank calendar. Once the calendar is open, click the blue hamburger menu (top right), then click **Print &amp; Export PDF**.

### Live demo calendars

Use on of Teamup’s live demo calendars to create your custom printable calendar. You can adjust the date and switch calendar views to print as many custom calendar views as you’d like.

1. Go to Teamup [live demos](https://www.teamup.com/live-demo/).
2. Click and launch any of the demos.
3. Click **the eye icon** above the calendar list on the left to hide all events.
4. Select the calendar view you want on the top right.
5. Adjust the dates or view configuration if needed, using the controls above the calendar.
6. From the blue hamburger menu, click **Print &amp; Export PDF**.
7. Choose your desired Print options: Full Color or [Eco-Mode](https://www.teamup.com/learn/printable-calendar-templates/printable-calendars-eco-mode/), hidden or visible sidebar, and page orientation.
8. Adjust the browser’s print settings if needed, then print.

### <span class="ez-toc-section" id="use-your-own-teamup-calendar"></span>Use your own Teamup calendar

If you already have a Teamup calendar, you can create custom printouts from it:

1. For a blank printable, [toggle](https://www.teamup.com/learn/interactive-demos/toggle-sub-calendars-on-and-off-from-view/) all the sub-calendars out of view so events are hidden.
2. Adjust the calendar view and date range as needed.
3. Adjust the dates or view configuration if needed, using the controls above the calendar.
4. From the blue hamburger menu, click **Print &amp; Export PDF**.
5. Choose your desired Print options: Full Color or [Eco-Mode](https://www.teamup.com/learn/printable-calendar-templates/printable-calendars-eco-mode/), hidden or visible sidebar, and page orientation.
6. Adjust the browser’s print settings if needed, then print.

You can also use a filtered view of your Teamup calendar to include selected events in your printable. [More details here](https://calendar.teamup.com/kb/how-to-quickly-print-a-filtered-calendar/).

### Printable blank calendar tips

- [Print calendars in Eco-Mode](https://www.teamup.com/learn/printable-calendar-templates/printable-calendars-eco-mode/) for reduced ink usage and better readability.
- In view with a [time grid](https://calendar.teamup.com/kb/change-time-resolution-grid-views/), adjust the [visible time range](https://calendar.teamup.com/kb/what-is-the-time-range/) to include only the time range you want on the printout.
- Use [link parameters](https://calendar.teamup.com/kb/calendar-link-parameters/#title) to create a more streamlined look or [change the title](https://calendar.teamup.com/kb/print-schedule-calendar-with-custom-title/) for each printout.
- We’ve also created a collection of[ blank calendars](https://www.teamup.com/printable-calendars/) to start with.
