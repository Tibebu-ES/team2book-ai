 </nav> </div><div class="hkb-article__content" itemprop="text">A **recurring or repeating event** is an event that will occur more than once on your calendar. Rather than creating an event multiple times, use the **Repeats** menu to create an **event series**.

Recurrence patterns
-------------------

Examples of supported recurring event patterns:[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2013/02/repeating-events-mobile-teamup.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2013/02/repeating-events-mobile-teamup.png)

- Weekly on Thursdays at 8:00AM, until December 31, 2019
- Every weekday at 8:00am, forever
- On the first Monday of every month at 10:00am, for 5 times
- Yearly on July 4, forever
- Every 2nd Wednesday for 5 times

Repeating events can be set to repeat Daily, Weekly, Monthly, or Yearly. You can customize these options further:

- Daily can be set to every day, every other day, every 3 days, etc.
- Weekly can be set to selected days in the week.
- Weekly can be set to every week, every 2 weeks, every 3 weeks, etc.
- Monthly can be set to every 2 months, every 3 months, etc., and set to a particular day: *10th day of the month* **or** *2nd Monday of the month*.
- Yearly can be set to every year, every 2 years, every 3 years, etc., and to a particular day, like the Monthly option.

Create a repeating event
------------------------

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2013/02/250904tu-repeating-events-browser.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2013/02/250904tu-repeating-events-browser.png)

To create a recurring event:

1. Click on the date you want the first instance of the event to occur.
2. Open the repeating options in the event editor: 
    - [Browser](https://calendar.teamup.com/kb/recurring-events/#in-a-browser): **Check the Repeats box**.
    - [Teamup app](https://calendar.teamup.com/kb/recurring-events/#in-the-teamup-app): Tap on **Does not repeat**.
3. The options for repeating events will open. Customize the recurrence pattern as needed.
4. Click **Done** or tap the **checkmark**, then **Save** the event.

**ℹ️ [Learn more](https://calendar.teamup.com/kb/recurring-events/)**

**Good to know:**

- The Signups feature can be used to sign up for [a single instance of a recurring event.](https://blog.teamup.com/2018/07/27/feature-update-signup-for-a-single-instance-of-a-recurring-event/)
- When you make changes to one instance of a repeating event, you will be prompted to choose whether your changes apply to that instance only, to that instance and all future instances, or to all instances in the event series.
- If you want to duplicate an event, but not create a recurring event series, you can [use the Copy event function](https://calendar.teamup.com/kb/video-how-to-copy-events/).
