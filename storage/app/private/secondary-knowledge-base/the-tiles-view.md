 </nav> </div><div class="hkb-article__content" itemprop="text">Tiles view, available on browser and [on the Teamup app](https://calendar.teamup.com/kb/how-to-use-calendar-views-on-teamup-mobile-apps/#switch-calendar-views), is a unique [calendar view](https://calendar.teamup.com/kb/how-to-use-calendar-views/) that shows each event in its own tile.

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2023/03/260105tu-app-tiles-view.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2023/03/260105tu-app-tiles-view.png)

Each event tile displays a cover image (if there is one uploaded to the event description or attachments field). And you can set the [event sort order](#set-event-sort-order) to chronological (calendar default) or reverse chronological (blog style). Tiles view is an excellent view for a clean, polished visual display of events and works well for many use cases:

- Ongoing events listings such as training programs, community events, sports club schedules, hobby group calendars, tours and event itineraries.
- Collecting memories, photo journaling, keeping travel and experience logs, parenting diaries, sharing photos from group and team events.
- Displaying conference agendas, team schedule planning for conference attendees, trade shows, corporate retreats, and business events.

How to use Tiles view
---------------------

1. Choose **Tiles** from the view selector.
2. Use the arrows or date picker as needed to adjust the visible dates.
3. Adjust the **Date range** and choose the **Group by** option (None, Week, or Month).
4. Set the **Tile size** to Small, Medium, or Large.

**View event details**: Click on an event tile to open that event.

**[Toggle calendars](https://calendar.teamup.com/kb/hide-calendars/)**: Click on the calendar title to show or hide a particular calendar’s events.

[**Filter events**](https://calendar.teamup.com/kb/filter-events/): Use built-in filters to sort events by keyword, custom field contents, etc.

Note: If you don’t see **Tiles** as an option in the view selector, ask your calendar admin to enable this view in settings (details below).

### Cover images

If an event has images, one of these will automatically be used for the event tile display.

You can control which image is used as the cover image by uploading an image with a file name that starts with “cover” to the Attachments field.

- Otherwise, the cover image is the last uploaded image in the Attachments field.
- If there are no images in the Attachments field, the cover image is the highest positioned image in the Description field.

If an event does not have an image, the event tile will have a header with a date icon; the color will match the assigned sub-calendar.

Embed Tiles view
----------------

Enable and configure Tiles view
-------------------------------

[![The Settings > Calendar views menu shows the option to enable Tiles view, set a default date range, default grouping, default tile size, and event sort order. ](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![The Settings > Calendar views menu shows the option to enable Tiles view, set a default date range, default grouping, default tile size, and event sort order. ](https://calendar.teamup.com/wp-content/uploads/2025/02/250303tu-setting-tiles-view-event-sort-order.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2025/02/250303tu-setting-tiles-view-event-sort-order.png)

### Enable Tiles view

[Calendar administrators](https://calendar.teamup.com/kb/what-is-the-calendar-administrator/) can enable Tiles view in **Settings** &gt; **Calendar Views**. Once enabled, Tiles view will be an option in the [view selector](https://calendar.teamup.com/kb/what-are-calendar-views/). These views are available to all current users.

### Set defaults

Configure the default settings for Tiles view by choosing from the options in each drop-down menu. Default settings include the default date range, default grouping, and default tile size.

Users can still adjust the settings while using the calendar in Tiles view (i.e., change the date range and tile size). The calendar will reset to defaults when a new browser session is started.

### Set event sort order

Set the event sort order by checking the button next to Ascending or Descending.

- When the event order is ascending (the default), the date range is calculated from the current day into the future.
- When the event order is descending, the date range is calculated from the current day into the past.

The sort order cannot be changed by users on the front end; it can only be configured in **Settings &gt; Calendar Views &gt; Tiles View**.
