<meta content="September 20, 2022" itemprop="datePublished"></meta> <header class="hkb-article__header">Print a Calendar or Event Using Browser’s Print Function
========================================================

 </header></head><body><div class="hkb-article__content" itemprop="text">You can print a Teamup calendar or event using [the PDF Print &amp; Export tool](https://calendar.teamup.com/kb/print-a-calendar/), which uses your browser’s print functionality.

Alternately, you can open your browser’s print dialog directly:

- On most browsers: Open the **File** menu, then select **Print**.

Or use the standard keyboard shortcuts:

- Windows &amp; Linux: **Ctrl + p**
- Mac: ⌘ **+ p**

<div class="mceTemp"></div> **Once the print dialog is open, adjust the page layout and other settings as needed.**

Then print or download a PDF.

To print your calendar in [Eco Mode](https://calendar.teamup.com/kb/print-a-calendar/#eco-mode-printing) (which reduces ink usage and provides better readability for printouts), use Teamup’s [PDF Print &amp; Export tool.](https://calendar.teamup.com/kb/print-a-calendar/)
