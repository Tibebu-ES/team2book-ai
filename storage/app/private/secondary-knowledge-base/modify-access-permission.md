 </nav> </div><div class="hkb-article__content" itemprop="text">The **Modify** access permission level is the most powerful level after [the administrator](http://blog.teamup.com/2018/12/05/what-is-the-calendar-administrator/). Modify permission does not allow access to [the calendar settings](http://blog.teamup.com/2018/12/05/what-are-the-calendar-settings/), but it does give the user full ability to add, modify, and delete any event on the shared calendar(s) at any time.

A person who needs to the ability to manage all events on the calendar can be given [**Modify permission** ](https://calendar.teamup.com/kb/what-are-access-permissions/#modify)to all sub-calendars. This allows them to add, update, and delete events but does not give them access to the calendar settings.

Modify permission
-----------------

If you have **Modify** access permission:

- You can add events to the calendar.
- You can see event details for all events on the calendar.
- You can modify any event on the calendar.
- You can delete any event on the calendar.

You can give someone modify permission to selected sub-calendars, and a lower level of access to other sub-calendars. This ability to customize permissions for each individual sub-calendar makes it possible for you to give as much autonomy as possible to calendar users, while protecting data or preventing unauthorized changes to other sub-calendars.

Modifier role
-------------

An [administrator](https://calendar.teamup.com/kb/calendar-administrator-access-explained/#who-gets-administrator-access) is a person who needs to access the calendar settings in order to add and manage sub-calendars, manage users, handle the subscription, and configure calendar settings.

- **We recommend limiting the administrator permission** to as few users as necessary. Do not share grant administrator access to someone unless they need to manage the calendar settings.

A modifier is a person who needs to have full capability to manage events, including adding new events, updating, or deleting existing events, on all sub-calendars. The modifier role does NOT need to have administrator access. Instead, they need to have **modify access to all sub-calendars.**

With modify access to all sub-calendars, they can manage (add, change, reschedule, delete) all events on the calendar.
