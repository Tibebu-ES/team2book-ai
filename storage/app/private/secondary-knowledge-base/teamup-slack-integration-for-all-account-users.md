Any [Teamup account user](https://calendar.teamup.com/kb/using-teamup-user-account/) can set up this integration to send Teamup notifications to their private Slack channel.

Calendar administrators: [Manage Slack integrations](https://calendar.teamup.com/kb/teamup-slack-integration-group-channels/) in the calendar settings.

Connect Teamup with Slack
-------------------------

<figure class="wp-block-image">[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2017/06/250729tu-slack-notifications-integration.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2017/06/250729tu-slack-notifications-integration.png)</figure>The Slack integration makes it possible for you to receive pop-up alerts on desktop or mobile devices via your Slack app. If you’re in Slack anyway, it’s an easy way to stay updated on what’s happening with calendar events.

Note that changes to past events will only trigger notifications if the calendar is on a [paid plan](http://www.teamup.com/pricing/).

To set up or modify a Slack integration, you must be logged into your [Teamup user account](https://calendar.teamup.com/kb/using-teamup-user-account/).

### Step 1: Connect with Slack

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2017/06/250707tu-set-up-slack-notifications.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2017/06/250707tu-set-up-slack-notifications.png)

1. Open Teamup in a browser.
2. Click the blue calendar menu (top right).
3. Select **Preferences &gt; Slack Integration.**
4. Click **Add to Slack**. This will take you to Slack.com to obtain the necessary authorization.
5. To authorize Slack: 
    - Sign in, if prompted to do so.
    - Select the Slack team.
    - Select the channel.
    - Click **Allow**<span style="text-align: center;"> to give Teamup permission to post notifications to Slack. </span>
    - After authorizing Teamup, you will be redirected to the Preferences dialog.

### Step 2: Configure Teamup notifications

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2017/06/250707tu-configure-slack-notifications.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2017/06/250707tu-configure-slack-notifications.png)

1. Set up notifications for **all sub-calendars** at once or **individually for each sub-calendar**.
2. Select the notification type: **All changes, New events,** or **Important changes.** Important changes include newly created events and date/time changes to existing events.
3. When done, click **Save.**

#### Set up notifications for all calendars

In the **All calendars** row, click the **Changes** menu and select the notification type. Click **Save.**

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2017/06/250708tu-slack-notif-all-calendars.gif)</noscript>](https://calendar.teamup.com/wp-content/uploads/2017/06/250708tu-slack-notif-all-calendars.gif)

#### Set up notifications for individual calendars

For each calendar, click the **Changes** menu and select the notification type for that sub-calendar. Select **None** if you do not want any notifications for a particular calendar. Click **Save.**

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2017/06/250708tu-slack-notific-selected.gif)</noscript>](https://calendar.teamup.com/wp-content/uploads/2017/06/250708tu-slack-notific-selected.gif)

### Test Slack notifications

Add, edit or delete a future-dated event in your Teamup Calendar and wait for the post from Teamup to appear in Slack. It should happen in approximately 60 seconds.

### Modify or turn off Slack notifications

[![](https://calendar.teamup.com/wp-content/plugins/native-lazyload/assets/images/placeholder.svg)<noscript>![](https://calendar.teamup.com/wp-content/uploads/2017/06/250708tu-modify-slack-notifs-users.png)</noscript>](https://calendar.teamup.com/wp-content/uploads/2017/06/250708tu-modify-slack-notifs-users.png)

1. Open Teamup in a browser.
2. Click the blue calendar menu (top right).
3. Select **Preferences &gt; Slack Integration.**
4. Your active Slack integrations will be listed. 
    - Click the **toggle** to turn an integration on or off.
    - Click the **pencil icon** to view and modify the notification settings.
    - Click the **trash can icon** to delete an integration.

To completely remove the Slack integration, after deleting the integration(s) in Teamup: In the Slack app, go to the [app directory ](https://slack.com/apps/manage)and delete the integration with Teamup Calendar.

Calendar administrators can [manage all notifications](https://calendar.teamup.com/kb/teamup-slack-integration-group-channels/#how-to-stop-slack-notifications) by going to **Settings &gt; Notifications.**
